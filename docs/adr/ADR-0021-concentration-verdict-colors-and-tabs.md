# ADR-0021: 集中度ダッシュボードの判定色とセクター配分との行き来

## Status
Accepted（2026-10-01、本人承認。ADR-0019 D6「判定・バッジ・色分けを付けない」を置き換える。D7「合成スコア・ランキングにしない」は維持）

## Date
2026-10-01

## Context

ADR-0019 は、集中度ダッシュボードに判定や色分けを付けなかった。提言書に評価基準が無く、叩き台の数字が独り歩きすることを避けるためだった。

実際に画面を見た本人から、次の2点を求められた（2026-10-01）。

1. 「分散が効いているかどうか」をひと目で分かるようにしたい。指標ごとに良い向きが違う（PC1寄与率は低いほど良く、実効ベット数は高いほど良い）ので、数字だけでは読み解きにくい。緑・赤などの色で効果が分かる見た目にしてほしい。
2. セクター配分画面との行き来が分かりにくい。入口が画面上部の小さな文字リンクだけで、集中度画面には戻る手段が見えない。

実データ（2026-10-01、保有127銘柄・計算対象121銘柄）の値は、PC1寄与率 15.3%、実効ベット数 5.08、上位5銘柄ウェイト 40.6%、銘柄間の平均相関 0.13 だった。

## Decision

### D1 指標ごとに3段階で判定し、色とラベルで示す

判定は指標ごとに独立して行い、5指標を1つにまとめない。3段階は UC-005（セクター配分）の「健全／やや偏り／偏り警告」と同じ考え方で、次のラベルと色を使う。

| 段階 | ラベル | 色 |
|---|---|---|
| `ok` | 分散OK | 緑 |
| `caution` | やや集中 | 黄（アンバー） |
| `concentrated` | 集中 | 赤 |

色だけに頼らず、必ずラベルの文字も添える。

### D2 しきい値（叩き台）

境界値は、より良い側ではなく**悪い側に含める**（たとえばPC1寄与率がちょうど25%なら「やや集中」）。

| 指標 | 良い向き | 分散OK | やや集中 | 集中 |
|---|---|---|---|---|
| PC1寄与率 | 低いほど良い | 25%未満 | 25%以上45%未満 | 45%以上 |
| 実効ベット数 | 高いほど良い | 8以上 | 3以上8未満 | 3未満 |
| 上位5銘柄ウェイト | 低いほど良い | 30%未満 | 30%以上50%未満 | 50%以上 |
| 対SOXベータ（ポートフォリオ） | 絶対値が小さいほど良い | 0.5未満 | 0.5以上0.8未満 | 0.8以上 |

- 対SOXベータは、負の値も半導体に連動する（逆向きの）集中なので、**絶対値**で判定する。
- 銘柄別の対SOXベータ、計算対象の銘柄数、カバー率には判定を付けない。
- 値が算出できない（`null`）指標には判定を付けない。
- これらの数字に統計的な根拠はない。提言書の「集中した状態」の目安（PC1寄与率60〜75%、ENB 2〜5、平均相関0.6〜0.7）と、実際の保有の値（上の Context）を見て置いた叩き台で、UC-005 の 40%／70% と同じく使いながら調整する。変更するときはこの表を更新し、`ConcentrationVerdictEvaluator` の定数を直す。

### D3 相関行列は背景色のヒートマップにする

セルの値を次の5区分に分け、背景色の濃さで示す。「連動が強い＝集中側」なので赤系、「逆に動く＝分散に効く」なので緑系にする。

| 区分 | 条件 | 色 |
|---|---|---|
| `strong` | 0.7以上 | 濃い赤 |
| `high` | 0.5以上0.7未満 | 赤 |
| `mild` | 0.3以上0.5未満 | 薄い赤 |
| `none` | −0.3より大きく0.3未満 | 色なし（ほぼ無関係） |
| `negative` | −0.3以下 | 緑 |

- 対角（自分自身との相関1.00）と、値が `null` のセル（値動きが全くない銘柄）には色を付けない。
- 週数が52本しかないため、±0.15程度のずれは偶然でも出る。そのため0.3未満を「ほぼ無関係」とする。

### D4 判定は純ロジックに置き、画面は色を割り当てるだけにする

- 判定ロジックとしきい値は `App\Services\Concentration\ConcentrationVerdictEvaluator` に置く（DB非依存）。
- `ShowConcentrationDashboardAction` が判定結果（`verdicts`）と相関の区分（`correlation_bands`）を返す。
- ビューは、段階・区分を色（バッジ・背景）に割り当てるだけで、しきい値を持たない。

### D5 セクター配分と集中度は、切替タブで行き来する

- 「セクター配分」と「集中度」の2つの切替（サブタブ）を、両画面のタイトルの下に同じ見た目で置く。いまの画面が選択中として強調される。
- 切替は、既存のグローバルナビのタブ数を増やさない（`docs/product/ui-guidelines.md` のタブ数6を維持）。集中度画面の表示中も、グローバルナビの「セクター配分」が選択中になる。
- セクター配分画面上部の文字リンク（ADR-0019 D6）は、切替に置き換えて削除する。

## Rationale

- **判定を付ける理由**: 指標ごとに良い向きが違い、数字だけでは「効いているか」が分かりにくい。基準が叩き台でも、色が付くほうが本人の目的（分散が効いているかの確認）に合う。基準の根拠が弱い点は、「叩き台である」ことをこのADRとUCに明記し、数字の変更を1か所で済ませる構造で補う。
- **3段階にした理由**: UC-005 と同じ段階数で読み慣れている。2段階だと境界の少しの差で赤になり、現状（実効ベット数5.08、上位5銘柄40.6%）の「完全に良いわけでも悪いわけでもない」状態が表せない。
- **合成スコアは作らない**: D7 のとおり。指標ごとの色を並べるだけで、総合点や順位は出さない。
- **サブタブにした理由**: 目的が近い機能は同じ領域にまとめる、というナビ方針に合う。7つ目のグローバルタブ（上限を超える）や、片方向のリンクだけ（行き来が不便）より分かりやすい。
- **採らなかった案**: 2段階（緑・赤）、グローバルナビに7つ目のタブ、戻るリンクだけを足す案、銘柄別ベータへの判定色。

## Consequences

- ADR-0019 D6 の「判定・バッジ・色分けを付けない」は、本ADRで置き換える（ADR-0019 には置き換えの注記を付ける）。UC-015 の業務ルール「判定を付けない」は「指標ごとの判定を付ける（合成スコアは作らない）」に改める。
- 画面上の見た目が変わる。DBスキーマの変更はない。
- しきい値は叩き台のため、実データが蓄積したら見直す。見直しの際、画面の「やや集中」が多くなりすぎる・少なすぎるといった状況が基準になる。
- Tailwind の既存クラス（バッジの緑・黄・赤）と、相関セルのインライン背景色（rgba）だけで実現でき、フロントの再ビルドは不要。
