# ADR-0023: 業種別の基準PER/PBRとの比較による割安・割高の色付け

## Status
Accepted（2026-10-03、CHG-0034。方向性とuse-cases.md の変更〔UC-002・UC-003〕を Gate 2 で本人承認）

## Date
2026-10-03

## Context

保有一覧・銘柄詳細では PER・PBR が数値で出るだけで、その値が高いのか安いのかを本人が自分で判断している。本人から「各銘柄のセクターから基準になる PER・PBR を出し、実際の値に対する割合で割高・割安を色付けで判定できないか。突出して良いものは色を濃くする二重の判定にし、色付けだけにするか判定にも生かすかを検討してほしい」との依頼があった（2026-10-02）。

実データ（2026-10-03）で分かった制約:

- 保有銘柄から業種の基準値を作るのは不適切。業種ごとの件数が1〜15銘柄で、本人が選んだ偏りがあり、外れ値（PER 370 など）で中央値が歪む。
- J-Quants 無料プラン・Finnhub 無料プランには業種別PER/PBRがない。
- 米国株のPBR（中央値7〜23）は自社株買いの影響で、日本株と水準が別物。
- 業種未分類の銘柄が多い（日本株64・米国株43、集計対象に過去の銘柄を含む）。
- 民間サイトの業種別PER/PBRは、定義（予想か実績か、単純平均か中央値か）で値が2〜5倍ずれる。

基準値は5つの調査（JPX 月次統計、TOPIX-17 ファクトシート、民間集計、Damodaran、SPDR ETF）で根拠を取った。値・出典・基準日は [`docs/product/valuation-benchmarks.md`](../product/valuation-benchmarks.md)、取得結果の原本は `docs/product/valuation-benchmarks-evidence/` にある。

## Decision

### D1 対象と範囲

- 個別株（`instrument_type`=`stock`）の PER・PBR に、業種の基準値との比較による判定を付ける。
- 表示する画面は、保有一覧（UC-002）の PER バッジと、銘柄詳細（UC-003）の PER・PBR。売買シグナル画面（UC-004・UC-010・UC-011）・新規投資候補（UC-012）・ウォッチリストへの展開は、この変更に含めない（後続のCRで検討する）。
- ETF・投資信託には判定を付けない（指標欄は従来どおり「対象外」）。
- 健全性指標（ROE・自己資本比率・営業利益率・成長率）への色付けはD9で追加する。

### D2 基準値は外部の固定表を使う

- 日本株: JPX 月次統計（東証17業種、プライム・連結、実績ベース、時価総額加重）の直近値。TOPIX-17 ファクトシートで照合する。
- 米国株: Damodaran の業種別集計PER（黒字企業のみ）と SPDR 等ウェイト系ETFの実績P/Eの相加平均。
- 民間サイトの集計は基準値に使わない（定義の差が大きいため）。
- 値・出典・基準日・信頼度は `docs/product/valuation-benchmarks.md` が正本で、実装は `config/valuation_benchmarks.php` に同じ内容を持つ。DBテーブルは作らない（更新は月次〜年次で、本人が手で行うため）。
- 画面には、基準値・基準日・出典を銘柄詳細で表示する。

### D3 判定は「実際の値 ÷ 業種の基準値」の比率で、5段階にする

PER と PBR は別々に判定し、合成しない（ADR-0021 D1 と同じ）。

| 比率 | 段階 | ラベル | 色 |
|---|---|---|---|
| 0.50未満 | `strong_cheap` | 強い割安 | 濃い緑 |
| 0.50以上0.80未満 | `cheap` | 割安 | 緑 |
| 0.80以上1.25以下 | `fair` | 並み | 色なし |
| 1.25超2.00以下 | `expensive` | 割高 | 黄（アンバー） |
| 2.00超 | `strong_expensive` | 強い割高 | 濃いオレンジ |

- 境界値は、より極端な段階ではなく、穏やかな側に含める（比率がちょうど0.50なら「割安」、2.00なら「割高」）。
- 割高は赤にしない。半導体などの成長株は常に割高に見えるため、危険信号に見せないための選択。
- 色だけに頼らず、必ずラベルの文字も添える。
- **判定は表示と同じ桁に丸めた値で行う**（ADR-0021 D2 と同じ理由）。PER・PBRと基準値は小数1桁に丸めてから比率を計算し、比率は小数2桁に丸めて段階を決める（PBRは表示が小数1桁のため同様）。

### D4 信頼度で、色の濃さと注記を変える

基準値ごとに信頼度（`high`／`medium`／`low`／`none`）を持つ。決め方は `valuation-benchmarks.md` の2章。

| 信頼度 | 表示 |
|---|---|
| `high` | 5段階で判定する（濃い色を含む） |
| `medium` | 濃い色（強い割安・強い割高）は使わず、緑・黄までにする |
| `low` | `medium` と同じで、さらに「基準が不安定」と注記する |
| `none` | 判定しない（色なし） |

「突出して良い／悪いものだけ色を濃くする」二重の判定は、信頼度が `high` の業種にだけ付ける。基準が不安定な業種で濃い色を出すと、基準の誤差を突出と誤認するため。

### D5 PBR の扱い

- 日本株: 全17業種で判定する（信頼度に従う）。
- 米国株: Utilities のみ判定する。それ以外は、簿価が意味を持たないため色なし（数値は従来どおり表示する）。業種を追加する場合は `valuation-benchmarks.md` を先に更新する。

### D6 判定なしの条件

次のいずれかなら、判定を付けない（色なし、詳細画面では理由を表示する）:

- PER/PBR が `null`、または0以下（赤字・自己資本マイナス）
- 業種が未分類、または基準表にない業種（日本株の「その他」を含む）
- 基準値の信頼度が `none`
- 銘柄が個別株でない

### D7 色付けのみとし、財務健全性・売買シグナルの判定には使わない

- 割安・割高は株価の水準で、財務健全性（自己資本比率・ROE・成長率・営業利益率）は企業の質で、軸が違う。混ぜると、質の良い成長株が「割高だから不合格」になる。
- 財務健全性は利確のしきい値（`TakeProfitThresholdEvaluator`）にも使われており、混ぜると売買シグナルの挙動が変わる。ユーザー向け挙動の変更になるため、実測のうえ本人の承認を得てから行う。
- 買い増しシグナルには既に PER・PEG を使う質つき割安（ADR-0016）があり、二重に効かせると影響が追えなくなる。
- 2026-09-27 の決定（新しいシグナル・しきい値は検証基盤の実測が先）に従う。
- **後続CR（本ADRの範囲外）**: シグナル発生記録（UC-014、`signal_occurrences`）に、そのときの割安・割高の段階を保存し、「強い割安だった銘柄は実際に成績が良かったか」を実測する。その結果を見て、判定への組み込みを改めて検討する。

### D8 判定ロジックは純ロジックに置き、画面は色を割り当てるだけにする

- 比率・段階・信頼度の扱いは `App\Services\Analysis\ValuationBenchmarkJudge`（DB非依存）に置き、基準値は `config/valuation_benchmarks.php` から読む。
- `ListHoldingsAction`・`ShowHoldingDetailAction` が判定結果を返し、ビューは段階を色（バッジ）に割り当てるだけにする。

### D9 健全性指標にも同じ二段階の色付けを付ける（2026-10-03 追加、本人承認。ラインは根拠調査のうえ同日改訂）

本人から「他の健全性の指標にも二段階の色付けを。評価ロジックに使わないにせよ、色を濃くするなどはどうか」との依頼があり、D7（判定には使わない）を保ったまま、表示だけを追加する。「突出」のラインは、外部の資料と保有銘柄の実データから根拠を取って決めた（根拠の詳細は [`docs/product/valuation-benchmarks.md`](../product/valuation-benchmarks.md) の7章）。

**対象**: ROE・自己資本比率・営業利益率・売上成長率・営業利益成長率。表示する画面は、銘柄詳細（UC-003）の各指標と、保有一覧（UC-002）の「売上成長」バッジ。売買シグナル画面の判定チェックリストは変更しない。

**段階**: 強い良好（濃い緑）／良好（緑）／基準未満（黄）／大きく下回る（濃いオレンジ）。緑（良好）の下限は現行の財務健全性の合格ラインと同じにし、画面の色と判定を食い違わせない。境界は「以上」で上の段階に含める（既存の判定〔10.0ちょうどは passed〕に合わせる）。「突出」＝上場企業の分布の上位おおむね10〜25%を目安にする。

**ライン**（強い良好は市場別。良好・基準未満・大きく下回るは日本株・米国株共通）:

| 指標 | 強い良好（日本株） | 強い良好（米国株） | 良好＝合格ライン | 基準未満（黄） | 大きく下回る（濃いオレンジ） |
|---|---|---|---|---|---|
| ROE | 15%以上 | 25%以上 | 10%以上 | 0%以上10%未満 | 0%未満 |
| 自己資本比率 | 70%以上 | 付けない | 40%以上 | 20%以上40%未満 | 20%未満 |
| 営業利益率 | 20%以上 | 30%以上 | 10%以上 | 0%以上10%未満 | 0%未満（赤字） |
| 売上成長率 | 15%以上 | 25%以上 | 0%超 | −10%以上0%以下 | −10%未満 |
| 営業利益成長率 | 30%以上 | 30%以上 | 0%超 | −20%以上0%以下 | −20%未満 |

（各段階は「強い良好の下限未満〜良好の下限以上」が良好。たとえば日本株のROE12%は良好、15%は強い良好。）

**ラインの根拠**（詳細は valuation-benchmarks.md 7章）:

- **ROE（日本株15%）**: 東証の公式資料（2026-03-01時点）でプライムの15%以上は19%、民間集計（EDINET DB、3,728社）の上位25%の境界が13.4%。上位約2割で、「突出」の範囲に入る。
- **ROE（米国株25%）**: Damodaran（米国5,994社）の業種別ROEの上位25%が社数加重で22.9%、上位10%が29.6%。S&P500のROEは20.2%（直近12か月）。日本株の15%は米国では上位4割にとどまるため、別ラインにした。
- **自己資本比率（日本株70%）**: 民間集計（3,775社）の中央値56.9%、上位25%の境界が71.2%。叩き台の50%は上位半分で突出とは言えない。保有銘柄の上位25%は68.5%。
- **自己資本比率（米国株）**: Damodaran の指標は有利子負債÷資本ベースで日本の自己資本比率と定義が違い、総資産ベースの分布を取得できなかったため、強い良好は付けない（良好・基準未満・大きく下回るだけ）。
- **営業利益率（日本株20%）**: 民間集計（3,566社）の中央値6.35%、上位25%が約11%、上位約3%が29.7%。20%は上位6〜10%程度（推計）。保有銘柄の上位25%は18.4%。
- **営業利益率（米国株30%）**: Damodaran の業種別営業利益率の上位25%が社数加重で23.9%、上位10%が29.5%。上位10%付近の30%を突出とする（本人が25%から30%へ修正、2026-10-03）。
- **売上成長率（日本株15%・米国株25%）**: 日本株は全上場の前年度比の分布を取得できず、業種内の上位25%が多くの業種で5〜11%（情報通信・サービスなどで15〜17%）のため、15%を上位10〜25%の目安（推計）にした。米国株は Damodaran の5年CAGRで上位25%が15.5〜18.5%、上位10%が21〜29%のため、上位10%寄りの25%とする（本人が20%から25%へ修正、2026-10-03）。**根拠は他より弱い**。
- **営業利益成長率（30%）**: 外部に分布の資料がない。保有銘柄の営業利益成長率は日本株の中央値15.4%・上位25%が34.9%、米国株の中央値17.0%・上位25%が47.3%で、15%では半数が超えるため突出にならない。保有銘柄のみを根拠にした叩き台。
- **下側のライン**（0%・−10%・−20%・自己資本比率20%）: 外部の根拠はなく叩き台。保有銘柄の下位10%が、売上成長率で−1.3%（日本株）、営業利益成長率で−13.6%（日本株）・−14.6%（米国株）なので、−10%・−20%は下位10%よりさらに悪い側。

**判定なしの条件**:

- 値が `null` のとき。
- 銀行・金融（除く銀行）は、自己資本比率と営業利益率に色を付けない。業態上意味を持たないため（自己資本比率の業種別中央値は銀行5%）。
- 不動産は、自己資本比率に色を付けない（業種別中央値34%で、レバレッジを使うのが通常のため。営業利益率・ROE・成長率は付ける）。

**その他**:

- 比率は表示と同じ桁（小数1桁）に丸めた値で判定する。色だけでなくラベル（強い良好／良好／基準未満／大きく下回る）の文字を添える。
- 判定ロジックは `ValuationBenchmarkJudge` とは別の純ロジック（`FundamentalMetricToneEvaluator`）に置く。良好の下限は `FundamentalHealthEvaluator` の定数（`MIN_ROE`・`MIN_EQUITY_RATIO`・`MIN_OPERATING_MARGIN`・`MIN_GROWTH_RATE`）を参照し、値を二重に持たない。強い良好・下側のラインは `config/valuation_benchmarks.php` に市場別に持つ。
- **財務健全性の判定（`FundamentalHealthEvaluator`）・利確しきい値・買い増しシグナルは変更しない。**

## Rationale

- **外部の固定表にした理由**: 保有銘柄から基準を作ると、母集団が小さく偏って「市場に対する割安・割高」にならない。無料APIに業種別PER/PBRがない以上、公式の集計値を手で置くのが現実的で、更新手順を決めれば維持できる。
- **JPX 月次統計を主にした理由**: 取引所の公式資料で、定義（実績ベース、時価総額加重）が明記されており、アプリの日本株PER（直近開示EPS基準）と整合する。TOPIX-17 ファクトシートとほぼ一致して裏が取れた。
- **米国株を Damodaran とSPDRの平均にした理由**: Damodaran は定義が明確（黒字企業のみの集計PER）で、アプリの TTM PER と整合するが、基準日が古く業種対応が粗い。SPDR の等ウェイトETFは新しいが、保有銘柄の加重調和平均であり、単独では偏る。2つの独立した出典の差を信頼度に反映する。
- **比率の5段階にした理由**: ADR-0021 の3段階に、突出した良し悪しを示す濃い色を足した。0.80・1.25 は逆数に近い対称な区切り、0.50・2.00 は「半分・2倍」で説明しやすい。値は叩き台。
- **判定に使わない理由**: D7 のとおり。まず色で見え方を作り、効果は実測してから判断する。
- **採らなかった案**: 保有銘柄内の中央値を基準にする案（母集団が小さく偏る）、全上場銘柄から自動算出する案（無料APIで取れない）、PER・PBRを合成した1つのスコア（ADR-0021 D1・ADR-0019 D7 と同じ理由で作らない）、割高を赤にする案、財務健全性の第5条件に組み込む案、DBテーブルに基準値を持たせる案（更新が稀で、設定ファイルで足りる）。

## Consequences

- 保有一覧・銘柄詳細の見た目が変わる（ユーザー向け挙動の変更。use-cases.md の UC-002・UC-003 を改訂し、Gate 2 の承認を得る）。DBスキーマの変更はない。
- 基準値は叩き台で、月次（日本株）・年次（米国株）に更新が要る。更新を忘れると基準が古くなるため、銘柄詳細に基準日を表示して気づけるようにする。
- 業種が未分類の銘柄は判定が付かない（日本株64・米国株43、`sectors:backfill` が未実行の可能性。実行は別作業）。
- JPX の値を出典明記で利用することを本人が承認した（2026-10-03）。
- 数値は5つの調査の取得結果を転記したもので、ETFの値は要約経由のため、実装前に主要な値を公式ページで目視確認する。
- 財務健全性・売買シグナルへの影響はない。後続CRで段階を記録して実測するまで、判定には使わない（D9の健全性指標の色付けも表示のみ）。
- D9により、銘柄詳細と保有一覧の健全性指標に色が付く（ユーザー向け挙動の変更。UC-002・UC-003に反映済み）。強い良好のラインは外部の分布と保有銘柄の実データから根拠を取って決めたが、売上成長率・営業利益成長率と下側のラインは根拠が弱く、叩き台。
