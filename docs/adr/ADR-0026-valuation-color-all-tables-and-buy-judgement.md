# ADR-0026: 売買シグナル画面などへの業種比較の色付けの展開と、買い増し判定のPER基準の業種相対化

## Status
Accepted（2026-10-04、CHG-0048。use-cases.md の変更〔UC-004・UC-010・UC-011・UC-012・UC-013〕と、D3の判定の変更を Gate 2 で本人承認）

## Date
2026-10-04

## Context

ADR-0023（CHG-0034）で、保有一覧・銘柄詳細のPER・PBRに、業種の基準値との比較による割安・割高の色付けを決めた。売買シグナル画面などへの展開は「後続CR」として範囲外にしていた。

本人から次の指示があった（2026-10-04）。

1. 整理検討（含み損）の表以外のすべての表に、この機能を反映してほしい。整理検討は、ラベル文字のみ（色なし）にする。
2. 買い増し候補のPER「≦15」は実際の買い増しシグナルの判定基準である。色だけでなく、判定そのものにも業種比較を反映するのが妥当ではないか。

現状の確認:

- 売買シグナル画面の4つの表（利確検討・買い増し候補・整理検討・キープ）とウォッチリスト（UC-012）は、PER・PBRを判定チェックリストのチップで表示している。買い増し候補のPERだけが、判定基準（≦15）を持つ項目で、ほかは基準なしのグレーの参考表示。
- `BuySignalDeterminationService::PER_UNDERVALUED_THRESHOLD = 15.0` は、(a) PER単体の割安シグナル（`per_undervalued`、ADR-0016 D2）と、(b) 成長率が低い銘柄の代替条件（PER≦15かつ配当利回り≧3%、ADR-0015 D3）の2か所で使われている。業種を見ない固定値のため、業種によって偏る（基準PERが12〜44と業種で大きく違う）。
- 試算（2026-10-04、PERのある個別株174件。本ADRの規則で計算）: 現行の該当は36件、新規則の該当は42件。変化があるのは8件で、新たに該当が7件（小売3088・機械7013・米国の半導体MU・NVDA・NXPI・QCOM・TSM）、該当しなくなるのが1件（商社・卸売8002、PER14.6、業種基準17.3なので比率0.84で「並み」）。残り166件は変わらない。新規則を適用できる銘柄は62件で、112件は従来の基準（業種未分類・信頼度が低い業種）のまま。

## Decision

### D1 展開する範囲

| 画面・表 | 表示 |
|---|---|
| 保有一覧（UC-002）・銘柄詳細（UC-003） | ADR-0023のとおり（Gate 2承認済み）。本CRと同じサイクルで実装する |
| 売買シグナル画面: 利確検討（UC-004）・買い増し候補（UC-010）・キープ（UC-013のhold表） | PER・PBRチップに、業種比較の色とラベルを付ける |
| 売買シグナル画面: 整理検討（UC-011） | PER・PBRチップに、業種比較の**ラベル文字のみ**（色なし）を付ける。ADR-0010 D6の「赤の単一極性」を維持する |
| ウォッチリスト（UC-012）の判定チェックリスト | 買い増し候補と同一構造のため、同じ表示にする |

### D2 チップの表示

- 色・ラベル・境界・信頼度による濃色の制御は、ADR-0023 D3・D4・D5・D6と同じ。PBRは、日本株は全業種、米国株は Utilities のみ判定する。
- 買い増し候補とウォッチリストのPERチップは、D3の判定項目なので、達成状態（達成・あと一歩・未達）の色が、そのまま業種比較の色になる。
- それ以外のPER・PBRチップは、従来どおり「基準なしの参考表示」で、達成数には数えない。判定なし（業種未分類・基準表にない・値が0以下など）は従来のグレー表示。

### D3 買い増し判定のPER基準を、業種に応じて置き換える（判定の変更）

対象は、PER単体の割安シグナル（`per_undervalued`）と、低成長銘柄の代替条件（PER≦15かつ配当利回り≧3%）のPERの条件。

- 業種の基準PERの信頼度が `high` または `medium` の業種: **比率（実際のPER÷基準PER、小数2桁に丸める）が0.80未満**で条件を満たす（ADR-0023 D3の「割安」以上）。
- 信頼度が `low` / `none` の業種、業種が未分類、基準表にない業種: 従来どおり**PER≦15**。
- PERが0以下（赤字）は、従来どおり条件を満たさない。
- 配当利回り≧3%の条件、PEGの条件、前提条件（直近13週以内の52週高値からの下落など）は変更しない。
- チップの基準の表示は「≦{0.8×基準PER}（業種基準{基準PER}の0.8倍）」とし、「あと一歩」の幅は既存のバッファ（基準の20%）を流用する。
- 米国株も、基準表にある業種は同じ規則。
- 利確検討（UC-004）・整理検討（UC-011）には、PERの判定ロジックがなく、変更しない。PBRは判定に使わない。

### D4 財務チップの二段階（ADR-0023 D9の展開）

利確検討・買い増し候補・キープ・ウォッチリストの財務健全性チップ（ROE・自己資本比率・営業利益率・成長率）で、達成（`met`）の色を、強い良好のライン（ADR-0023 D9。日本株／米国株別）を超えたときだけ濃い緑にし、ラベル「強い良好」を添える。整理検討は色なし（赤の単一極性）。判定ロジックは変更しない。

### D5 計測のための記録（後続）

D3は、2026-09-27の「新しいシグナル・しきい値は検証基盤の実測が先」の決定を、本人の指示で先に進めるもの。効果を実測できるよう、後続のCRで、シグナル発生記録（UC-014）に「判定に使った基準（業種相対か固定か）」と、そのときの割安・割高の段階を保存する。本ADRの範囲外。

## Rationale

- **判定にも反映する理由**: 固定の「15」は業種を見ない。基準PERが12〜44と業種で違うため、建設・資材のPER13.3（基準13.9で割安ではない）が割安扱いになる一方、小売のPER17.4（基準27.7で割安）が割安扱いにならない。色と判定が食い違うのも避けられる。
- **信頼度が高い業種だけにした理由**: 基準が不安定な業種（例: 電機・精密は大型株の影響でPER43.5に歪む）で相対判定を使うと、誤って割安と判定する銘柄が増える。ADR-0023 D4の信頼度をそのまま使い、足りない部分は従来の基準で補う。
- **整理検討だけラベルのみにした理由**: ADR-0010 D6が、整理検討は赤の単一極性としているため。
- **採らなかった案**: 色付けのみで判定は固定の15のまま（表示と判定が食い違う）、すべての業種を相対判定にする（基準が不安定な業種で誤判定が増える）、PBRも判定に使う（PBRは簿価の意味が業種で違う）。

## Consequences

- 買い増し候補とウォッチリストの買い増しシグナルの出方が変わる（試算では174件中8件）。ユーザー向け挙動の変更で、use-cases.md の改訂と Gate 2 の承認が要る。
- 買い増し候補のPERチップの基準と達成状態が、業種ごとに変わる。「技術 x/9」の達成数が変わる銘柄が出る。
- `BuySignalDeterminationService` が、銘柄の市場・業種を受け取る必要がある。保有・ウォッチリストとも業種は保存済み。
- ADR-0016 D2（PER単体シグナルの閾値15.0）とADR-0015 D3（低成長の代替条件）を、本ADR D3で部分的に改訂する。両ADRに注記を付ける。
- 基準値の更新（月次・年次）が、判定にも影響する。基準値の更新時は、シグナルの出方の変化に注意する。
- 実測は後続のCR（D5）で行う。それまでは、判定の効果は未検証。
