# ADR-0030: 日本株の財務指標を、項目ごとに適切な開示行から計算する

## Status
Accepted

## Date
2026-10-09

## Context

CHG-0049 段階0の J-Quants Light の効果の見積もり（[PoC結果記録](../product/qualitative-signal-poc-results.md)）で、日本株の財務指標の計算元に不具合が見つかった。

`FundamentalIndicatorMapper::map()` は、`JQuantsClient::fetchStatements()` が返す開示行のうち、種類を見ずに最新の1行（`$statements[0]`）から PER・PBR・ROE・自己資本比率・営業利益率・配当利回り・配当性向を計算している。J-Quants `/v2/fins/summary` の実データ（2026-10-09、日本株149銘柄）では、最新の行が次のどれかになる。

| 最新の行 | 銘柄数 | 起きていること |
|---|---|---|
| 通期決算（FY） | 94 | 正しい |
| 四半期決算（1Q〜3Q） | 52 | ROE・年間配当は通期の行にしか入らないため空。1株純資産（BPS）も41銘柄で空。EPS・売上・営業利益は**期首からの累計**なので、PER が過大になる（DBに履歴がある29銘柄で、通期EPSとの比は最大6.7倍。例: 2914 の PER が約25のところ65.1） |
| 業績予想・配当予想の修正 | 3 | 実績がすべて空なので、指標がすべて空 |

DB（`fundamental_indicators`、日本株149件）でも、ROEが空70件・PERが空33件・自己資本比率が空25件だった。PER は買い増し判定（ADR-0026）、ROE・自己資本比率・営業利益率は財務健全性の判定（`FundamentalHealthEvaluator`）に使われるので、シグナルにも影響している。

あわせて、業績予想・配当予想の修正の行（`DocType` が `EarnForecastRevision` / `DividendForecastRevision`）は、`CurPerType='FY'` と `CurFYEn` を持ち、実績は空であることを確認した（例: 3010、6503）。ADR-0012 の成長率の計算は「FY の行を会計年度で重複排除し、最も新しく開示された行を使う」ため、修正の行が通期決算の実績の行より後、または同じ日に開示されると、その行が「最新の通期決算」と誤認され、成長率が空になる。`financial_statements` にも実績が空の行として保存されている。

この不具合は、無料版（12週遅れ）でもすでに起きている。Light に切り替えると、四半期決算が遅れずに見えるため、最新の行が四半期になる銘柄が大幅に増える。

## Decision

- **D1: 業績予想・配当予想の修正の行は、取得の段階で除外する。** `JQuantsClient::fetchStatements()` は `DocType` が `EarnForecastRevision` または `DividendForecastRevision` で始まる行を捨ててから、新しい順に並べて指定件数に絞る。これにより、指標の計算・成長率の計算・`financial_statements` への保存のいずれにも、修正の行が入らなくなる。
- **D2: 1年分の値（フロー）と、それを元にした指標は、最新の通期決算の行から計算する。** 対象は PER（EPS）・ROE・営業利益率（売上・営業利益）・配当利回り（年間配当）・配当性向。「最新の通期決算の行」は ADR-0012 の成長率と同じく、`period_type === 'FY'` の行を `fiscal_year_end` で重複排除した中で最も新しい会計年度の行とする。その行の値が空なら指標も空にする（古い年度には遡らない）。
- **D3: 時点の値（ストック）は、値がある最新の実績の行から取る。** 対象は自己資本比率（`equity_to_asset_ratio`）と 1株純資産（`book_value_per_share`、PBR）。四半期の貸借対照表が通期より新しいので、値があればそれを使う。四半期で空なら、次に新しい行に遡る。
- 米国株（Finnhub、`UsFundamentalIndicatorMapper`）は対象外で、変更しない。

## Rationale

- **PER を実績（直近の通期）EPSで計算する理由**: 業種比較の色付けと買い増し判定の基準にしている JPX の業種別PERが、実績ベースだから。予想PER（`FEPS`）は会社予想に依存し、比較の基準と揃わない。四半期の累計EPSを年換算する案は、季節性のある業種で歪むため採らなかった。
- **ROE・営業利益率・配当も通期にそろえる理由**: ROE と年間配当は J-Quants が通期の行にしか入れない。営業利益率は四半期の累計でも比率としては計算できるが、季節性で判定（10%以上）が揺れるため、ROE と同じ通期にそろえた。
- **自己資本比率・PBR は最新の行を使う理由**: 貸借対照表の値は累計ではなく期末の時点の値なので、四半期の値をそのまま使える。より新しい情報を捨てる理由がない。
- **修正の行をクライアントで除外する理由**: 修正の行は「実績」ではないので、実績を扱う下流（指標の計算・成長率・`financial_statements`）すべてに不要。下流ごとに除外すると漏れが出る。将来、業績予想の修正を注記に使う（CHG-0049）場合は、別のメソッドで取得する。
- **採らなかった案**: 全項目を最新の通期決算から計算する案（自己資本比率・PBR が最大約1年古くなる）。ROE・BPS・配当だけを直す案（PER が過大なまま残る）。どちらも本人と比較のうえ見送った（2026-10-09）。

## Consequences

- 最新の行が四半期決算の銘柄で、PER が下がり（実態に近づき）、ROE・PBR・配当利回り・配当性向が表示されるようになる。財務健全性の判定・買い増し判定・利確検討の判定チェックリストの結果が変わる銘柄が出る。ユーザー向けの挙動の変更なので、本人が承認した（2026-10-09）。
- 修正後の値は、次回の外部データ取得（CSV取込・ウォッチリストの更新）で入れ替わる。過去にDBへ保存された値は、取得し直すまで古いまま。
- `financial_statements` に保存済みの、修正の行に由来する実績が空の行は、自動では消えない（新しく保存されなくなるだけ）。
- 営業利益率は、最新の行が四半期決算の銘柄で、従来の「四半期の累計」から「直近の通期」に変わる。
- Light に切り替えても、この計算方法のままで指標が空にならない。
