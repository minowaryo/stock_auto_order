# docs/adr/

Architecture Decision Records for the project built from this template.

This directory starts empty. Record your own project's decisions here (e.g. frontend stack
selection, schema changes) using `/adr`, starting from `ADR-0001`.

Decisions about the template/harness itself (AI development policy, TDD enforcement, E2E
tooling, etc.) live in [`meta/adr/`](../../meta/adr/) and are not part of this sequence.
