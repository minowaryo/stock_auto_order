# glossary.md — 用語集

> プロジェクト固有の用語・略語を定義します。
> AIと人間の共通言語にするために正確に記載してください。

## ドメイン用語

| 用語 | 説明 | 別名 |
|---|---|---|
| RSI | 相対力指数。14期間を基本とし、買われすぎ/売られすぎを判定するテクニカル指標。高水準からの反落を利確シグナルの根拠の一つとして使う | Relative Strength Index |
| MACD | 12/26/9期間の移動平均線の差分から売買タイミングを判定するテクニカル指標。デッドクロス発生をトレンド終了サインとして扱う | - |
| ボリンジャーバンド | 移動平均線±2σの範囲でボラティリティ・過熱感を判定するテクニカル指標 | BB |
| ゴールデンクロス/デッドクロス | 短期移動平均線（MA20）が長期移動平均線（MA75）を上抜け/下抜けするシグナル | GC / DC |
| PER | 株価収益率。株価の割高/割安を判定するファンダメンタルズ指標 | Price Earnings Ratio |
| PBR | 株価純資産倍率。株価の割高/割安を判定するファンダメンタルズ指標 | Price Book-value Ratio |
| ROE | 自己資本利益率。資本効率を判定するファンダメンタルズ指標 | Return On Equity |
| 含み益 | 保有銘柄の評価損益（未実現の利益）。+20%超を利確シグナル判定の対象範囲とする | 評価損益 |
| セクター配分 | 保有銘柄を業種別に集計した比率。特定セクターへの偏り（70〜80%超等）をリバランス提案の根拠にする | 業種配分 |
| 分割指値 | 利益確定を一括ではなく複数回の指値に分けて行う運用方針（例: +20%地点で1/3、+35%地点で1/3、残りはトレンド追従） | - |
| 利確シグナル | 含み益到達・RSI反落・MACDデッドクロス等を根拠に、利益確定の検討タイミングを示す判定結果 | - |
| ラストワンマイル利確 | 含み益が一定水準（例: +20%）を超えた銘柄の利益確定判断に対象範囲を絞った本システムの分析スコープ | - |
| J-Quants | JPX（日本取引所グループ）公式のデータAPI。銘柄の業種分類（17業種コード/33業種コード）・財務諸表取得に使用。無料プランはデータが12週間遅延するため業種分類・ファンダメンタルズ用途に限定 | - |
| 17業種コード/33業種コード | J-Quantsで取得できる日本株の業種分類コード。セクター配分集計に使用 | - |
| リバランス | ポートフォリオ全体のセクター配分の偏りを是正する提案・調整 | - |
| 市場全体指標 | 日経平均・S&P500・米国10年債利回り・VIX指数・USD/JPY為替レートの総称。個別銘柄シグナルには自動反映せず、参考表示に留める | マーケットインジケーター |
| VIX指数 | シカゴ・オプション取引所が算出する米国株式市場の予想変動率指数。値が高いほど市場のリスクオフ心理が強いことを示す「恐怖指数」 | 恐怖指数 |
| 米国10年債利回り | 米国10年物国債の利回り。特にAI・半導体等のグロース株のバリュエーションに影響しやすいため参考指標として採用 | 米国長期金利 |

## 技術用語（プロジェクト固有の使い方）

| 用語 | このプロジェクトでの意味 |
|---|---|
| Action | 単一責務のビジネス操作クラス（`app/Actions/`） |
| Service | 複数Actionを束ねる上位サービスクラス（`app/Services/`） |
| ADR | Architecture Decision Record（意思決定記録） |
| Gate | Laravel認可の仕組み（Policy経由で呼ぶ） |
| RCID | Requirement Change ID（要件変更ID・トレーサビリティ用） |

## ステータス定義

| ステータス | 意味 |
|---|---|
| pending | CSV取込がアップロードされ、パース待ちの状態 |
| processing | CSVパース・指標計算を実行中の状態 |
| completed | 取込・指標計算が正常に完了した状態 |
| failed | CSVの形式不正・パースエラー等で取込に失敗した状態 |
