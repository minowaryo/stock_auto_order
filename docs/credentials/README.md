# credentials — 開発用認証情報の記録場所

開発中に必要になった認証情報（APIキーの参照先、テスト用アカウント情報等）を記録する場所です。
`docs/original-docs/` とは異なり、AIによる新規作成・編集・参照は可能です。

## ⚠️ AI向け注意事項（`.claude/rules/40-security.md` 参照）

- 実際の値（本番APIキー・パスワード・トークン等）を**チャットの応答・コミットメッセージ・PR説明にそのまま出力・引用しない**
- このディレクトリは `.gitignore` に登録済み。リポジトリにはコミットしない（ローカル・開発環境限定）
- 本番シークレットの実体はSecret Managerで管理する。ここに置くのは「どこに何が保管されているか」の参照情報や開発用ダミー値に留める
- 本番相当の値を見つけた場合は、そのまま扱わずユーザーに確認する

## 置いてよいもの

- 開発・テスト環境用のダミー認証情報
- 本番シークレットの保管場所への参照（例: 「Stripeテストキーは1Passwordの`xxx`に保管」）
- ローカル開発用の一時的なトークン・認証情報のメモ

## 置いてはいけないもの

- 本番環境の実際のAPIキー・パスワード・トークン
- 個人を特定できる認証情報
