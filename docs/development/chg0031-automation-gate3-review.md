## 主要判断

| 課題 | 設計での扱い |
|---|---|
| 取得済みなのに企業名等を再入力する | 原フィールド→資料版→未確認下書き→本人照合後の調査記録へ渡す |
| 同URLの訂正を見落とす | 既存source_itemsを上書きせず、今回の解析値/必要節を別の版へ追記。再解析/取り込み時に版を検証 |
| 自動文を「自分の要約」にする | 発見経路にgenerated_summaryとinput_originを追加。summaryは本人追記、checked_onは実際の本人操作日 |
| 複数企業を1取得項目の単一FKへ押し込める | 下書きごとに資料/取り込み先/発見経路/根拠版を関連付ける |
| 同名/親子会社を自動で上場確定する | 公式上場スナップショットと本人確認別名から候補を提示。未確認のまま既存research_entity_listingsへ書かない |
| 再取得で保留/訂正/見送りが消える | 抽出値・本人訂正・処理状態・資料への現在の掲載有無を分け、専用履歴へ追記 |
| NEDO最初の3件を何度も読む | 未取得優先→古い試行順、24時間間隔、最大3件/回。未解析/失敗/資料のみを別に表示 |
| 起動負荷/同時実行 | 取得時は必要フィールドを一時JSONへ記録。既存確認後に同期直列/200件ずつ処理し、既存研究ロック共用・全体120秒。HTTPなしの短いDBトランザクションで保存 |

## 正規データ経路の確認（2026-10-19）

- [NEDO実施予定先の例1](https://www.nedo.go.jp/koubo/CD3_100437.html)で実施予定先と再委託先の節、[例2](https://www.nedo.go.jp/koubo/CD3_100433.html)で同一採択枠の複数法人を確認。見出しから必要節だけを扱い、問い合わせ/委員PDFは取得しない。これらの会社の投資判断は行わない。
- [JPX公式一覧](https://www.jpx.co.jp/markets/statistics-equities/misc/01.html)は2026年9月末版・月次更新。HTMLから実際の配布リンクを取り直し、`.xlsx`を確認した。過去形式を推測した`.xls` URLは404だったため採用しない。実ファイルは266,304bytes、4,448行（見出し含む）、基準日2026-09-30。見出しは日付/コード/銘柄名/市場・商品区分と業種/規模の計10列。SHA256は`a26fdf4420cb6a152a1811ce0c6e293e642c8a99f1cc2ad9c47a5d55f2722c82`。スナップショットは`/tmp/chg0031-jpx-listing-20261019.xlsx`、本体はリポジトリへ追加しない。
- [SECの公開対応表](https://www.sec.gov/files/company_tickers_exchange.json)は`fields: cik/name/ticker/exchange`を確認。OTCも含まれるため、全行を日米の取引所上場企業として数えない。[公式説明](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)でも対応の精度/範囲は保証されず、[アクセス条件](https://www.sec.gov/about/developer-resources)を守る必要がある。
- [PhpSpreadsheetの公式読込手順](https://phpspreadsheet.readthedocs.io/en/latest/topics/reading-files/)を確認。値のみモードでも数式は残るため、別途の拒否/無計算とXlsx形式固定/展開上限を設計に含めた。依存の導入可否の実測はGreen時に行う。

## 実装を分ける順序

1. Gate 3承認後、FDAの資料版/下書き/公式マスタ/本人取り込みと新画面の最小フローをRedへ。候補生成はFDAから有効にして一式を確認する。
2. NEDOの後続取得/複数法人/役割/待ち行列を別サイクルでRed→承認→Green。検証済みの一覧パーサ24件は再作成しない。
3. H02の題名抽出/別名対応を追加。日米/3テーマの実資料検証、UC-012導線E2E、運用の停止/再起動を確認する。YouTubeのAPI条件は別案件の設計差分へ残す。

各サイクルに追加Gate 4が必要。情報源品質は11/02以降の別再精査で、単なる取得成功/固定サンプル合格で品質合格としない。main/実アプリ/本人データの変更とcommit/merge/pushは今回の作業に含めない。
