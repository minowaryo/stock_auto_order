# CHG-0031 JPX正式5桁コード・追加Red審議資料

2026-10-19。UC-016 / ADR-0033 D4。**本補足案と追加Gate 4は本人承認済み（2026-10-19）。Green修正・実JPX解析・関連304件成功。**

## 発見した問題

承認済みFDA追加79件と既存関連の計301件が成功後、既取得のJPX実配布Xlsxを新パーサへ渡したところ`catalog_invalid_row`で全件拒否した。データ4,447行中7行に正規の5桁コードがあり、アプリの4桁検証をマスタ全体へ流用しているため。

- 原ファイル: 266,304bytes、基準日2026-09-30、見出しを含め4,448行。
- SHA256: `a26fdf4420cb6a152a1811ce0c6e293e642c8a99f1cc2ad9c47a5d55f2722c82`、取得時と一致。
- 読取拒否まで0.7263秒・最大メモリ43MiB。DB更新や外部再取得はしていない。
- [JPX用語集の株式銘柄コード](https://www.jpx.co.jp/glossary/ma/429.html)で4桁固有名と1桁予備コード、普通株と新株/優先株等の正式表示の違いを確認。末尾を捨てて4桁へ同一化する方法は採らない。

## 修正提案・承認対象

[ADR-0033補足案](../adr/ADR-0033-research-candidate-automation.md#jpx正式5桁コードの補足2026-10-19本人承認済み)。公式上場マスタへ正規の4桁/5桁を原形式で保存し、現アプリの自動照合は4桁だけに限定する。5桁の法人は未同定の下書きとして保持する。既存の保有/CSV/ウォッチリストの4桁仕様、SEC照合、DB構造は変えない。

## 追加Red

[UC016ResearchListingCatalogJpxCodeTest](../../tests/Feature/UC016ResearchListingCatalogJpxCodeTest.php)と[架空混在資料](../../tests/Fixtures/ResearchAutomation/jpx-mixed-formal-codes.xlsx)を追加。資料は架空の4行で、普通株と別種類の同名/別名を含む。

| ケース | 意図 |
|---|---|
| 正式5桁を丸めず普通株と同じ全件公開版へ保存 | 4行を原コードのまま公開し、既存コードと混同しない |
| 同名4桁だけ自動照合し5桁の別名を混同しない | 5桁向けの別名を普通株へ流用しない |
| 5桁しか一致しない法人も下書きに残す | 4桁の推測、上場確定、保有/ウォッチリスト生成をしない |

専用MySQL DB `testing_chg0031_source_adapters`で**3件すべて失敗、9assertions、エラー0、11.35秒**。3件ともマスタが`published`になるべきところ`failed`となるassertionで失敗しており、接続/依存/fixtureのセットアップエラーではない。その後の保存/照合assertionは未到達で、Greenで検証する。

証跡: `storage/logs/automation-jpx-formal-code-red-20261019.xml`（git管理外）。構文/Pint成功。テストの作成者と主セッションで公式仕様/原データ/ケースを照合。独立した別エージェントが公式説明/架空Xlsx4行/3ケース/実行JUnitを1回確認し、HIGH/MEDIUM指摘なし。既存79件/関連301件のGreenとは別に管理し、全テストGreenとは報告しない。

## Green後の完了条件

追加3件と関連回帰、同じ原JPXファイルの全件解析を検証する。取得できることを情報源品質の合格とは扱わず、品質再精査は11/02以降。main/実アプリへの適用・commit/merge/pushは本承認の対象外。

## 承認（2026-10-19）

本人が「補足案と追加Red3件を承認して修正へ進む」を選択。本補足と3ケースを承認済みへ更新し、JPX正式コードの読取/自動照合の最小修正へ進む。保有/CSVのコード仕様とDB構造は変更しない。

## Green修正と実配布再検証

`ResearchListingCatalogParser`は正規4桁の後に非0の予備数字を付けた正式5桁を原形保存し、`ResearchListingCatalogService`は日本株自動照合を既存4桁検証に適合する行へ限定した。5桁の別名を4桁へ流用しない。既存の不正コード/壊れた構造の全件拒否、SEC処理、DB構造、保有/CSVの検証は変更していない。

同じ実Xlsxを再解析し、**4,447行すべて成功（4桁4,440・正式5桁7）**、基準日2026-09-30、266,304bytes、SHA256取得時と一致を確認。0.8242秒・最大47MiB。DBへの実資料投入や外部再取得なし。テスト用の合成資料と実ファイルを分け、取得/解析成功を情報源品質の合格とは扱わない。構文/Pint2ファイル成功。
