# 投資調査の作業記録

ここは本人のメガトレンド仮説や個別企業の調査カードを置く場所。`docs/product/`の要件・UC・ADRの承認資料とは分ける。

- [メガトレンド情報源の試行ログ](megatrend/source-pilot-log.md)と個別カードは、公開資料から得た事実、解釈、反証、未確認事項を記録する。
- 個別カードはアプリの機能要件、銘柄の購入推奨、本人の投資判断を確定しない。CHG-0031の要件検討には試行ログの集計を用い、個別カードの投資判断を仕様に転記しない。
- 個人の保有情報や有料メルマガ本文をここに複製しない。公開資料のURLと自分の要約を記録する。
