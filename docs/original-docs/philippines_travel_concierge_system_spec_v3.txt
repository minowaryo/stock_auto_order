1. サービス概要
==================================================

1.1 サービス名称（仮）
- Philippines Travel Concierge
- Clark & Angeles Travel Concierge
- フィリピン男性一人旅コンシェルジュ

1.2 サービスの基本コンセプト
日本人旅行者、特に30代前半〜50代前半の男性を主な対象とし、
フィリピン、特にマニラ・クラーク・アンヘレス周辺の旅行前相談、
現地移動情報、アクティビティ情報、安全情報、
必要に応じた信頼できる現地ドライバーの紹介を提供する。

1.3 サービスの価値
- 初めてのフィリピン旅行に対する不安を解消する
- Grabを標準の移動手段として案内し、旅行者が自力で安全に移動できるよう支援する
- ドライバー紹介は初期MVPでは提供せず、将来オプションとして検討する
- 画一的なツアーではなく、旅行者の体力・興味・予算・夜型／昼型に応じて柔軟なプランを提案する
- マニラ、クラーク、アンヘレスの現地情報を日本語で提供する
- Ryo本人の実体験に基づくアクティビティレビューを提供する
- 初期MVPでは、旅行情報・Grab利用支援・旅程設計・アクティビティ情報の品質で差別化する
- 将来に備え、管理者が候補ドライバーを簡易登録・評価できる内部機能のみ保持する

1.4 提供しないサービス
以下は本サービスの対象外とする。
- 女性の紹介
- 性的サービスの斡旋
- 性的サービスの価格交渉
- 店舗との交渉代行
- 違法サービスの予約・手配
- 売春、薬物、違法賭博その他の違法行為への関与
- 無許可・無保険の有償送迎の紹介
- 法令上旅行業登録等が必要となる旅行商品の販売・包括手配（事業形態確定前）

1.5 MVPの最重要方針
- 初期サービスではGrabの利用支援を中心にする
- ユーザー向けドライバー関連機能は実装しない
- ドライバー紹介・予約・決済・マッチングは提供しない
- ドライバー候補情報は管理者の内部メモとしてのみ保持可能
- ユーザーアカウントやマイページも初期MVPでは不要
- 申込、アンケート、Zoom相談、旅程提案、記事コンテンツを最優先とする

2. 想定ユーザー
==================================================

2.1 メインターゲット
- 30代前半〜50代前半の日本人男性
- 一人旅、または2〜4名程度の少人数グループ
- 初めて、または数回目のフィリピン旅行
- 英語に不安がある
- 東南アジア旅行に興味がある
- 観光、温泉、乗り物系体験、ナイトライフに関心がある
- 安全や移動にお金を払う意思がある
- 3泊4日〜5泊6日程度の短期旅行を想定

2.2 サブターゲット
- 海外旅行経験はあるが、現地調査の時間を削減したい人
- 3〜4名グループでアクティビティを楽しみたい人
- クラーク空港直行便を使いたい人
- マニラ〜アンヘレスの長距離移動だけ信頼できる車を利用したい人

2.3 想定ペルソナ
例:
- 42歳、日本在住、会社員、独身
- 年収600〜1,000万円
- 海外旅行は年1〜2回
- 英語は簡単な会話程度
- 成田からクラーク空港へ直行
- 4泊5日、予算20〜30万円
- Puning Hot Spring、ATV、乗馬、セスナ、カート等に関心
- 夜はバーやクラブのあるエリアで自由時間を持ちたい
- 深夜移動や郊外移動には信頼できるドライバーを希望

- キャンセル条件

5.2 柔軟に変更可能な項目
- マニラ観光
- 昼食
- カフェ
- ショッピング
- マッサージ
- カート
- ATV
- 乗馬
- 一部アクティビティの日付
- 夜の自由時間
- 出発時刻
- 翌日の昼予定

5.3 柔軟性の考え方
- 全体の60〜70%を事前に決定
- 30〜40%は現地状況に応じて変更
- 前日の夜が遅かった場合は翌日の昼予定を後ろ倒し
- Puningやセスナは予約・天候依存のため変更制限あり
- スパ、カート、ショッピングは代替候補として使う

2. 日程、人数、目的、予算等を入力
3. 希望日時を選択
4. 利用規約と免責に同意
5. 申込完了
6. 管理者へ通知
7. Zoomリンク送付

9.2 旅行プラン作成
1. 管理者がアンケート閲覧
2. 固定項目を設定
3. 柔軟項目を設定
4. 代替候補を設定
5. 予算目安を設定
6. ユーザーへ共有
7. ユーザー承認

9.3 Grab利用支援
1. ユーザーの到着空港、ホテル、移動予定を確認
2. Grabで対応可能な区間か確認
3. 乗車場所、目的地設定、料金目安、支払い方法を案内
4. 深夜、荷物、通信環境等の注意事項を案内
5. Grabが適さない場合は、ホテル送迎や正規送迎会社等の代替手段を一般情報として提示
6. 初期MVPでは個別ドライバーの紹介・予約手配は行わない

9.4 当日変更
1. ユーザーがチャットで変更希望
2. 管理者が変更可能性を確認
3. ドライバー・アクティビティ事業者へ確認
4. 追加料金・キャンセル料を提示
5. ユーザー承認
6. 旅程更新

- 個人情報暗号化
- 監査ログ
- ログイン試行制限

- MVP: 月間99.5%
- 本番: 99.9%目標
- 自動バックアップ
- 障害ログ
- エラーモニタリング

14.3 パフォーマンス
- 主要ページ3秒以内
- 画像最適化
- CDN利用
- キャッシュ
- DBインデックス

14.4 モバイル対応
- スマートフォン最優先
- 日本語UI
- 英語切替を将来対応
- LINE、WhatsAppへの導線

14.5 プライバシー

- 保存期間設定
- 削除依頼対応
- 機微情報の非収集

15. 法務・運用上の境界線
==================================================

15.1 サイト上の表現
推奨:
- 旅行コンシェルジュ
- 現地移動サポート
- ドライバー紹介
- 旅行前相談
- モデルプラン提案
- ナイトライフエリア情報
- 自由時間
- 安全な移動支援

避ける:
- 夜遊び完全サポート
- 出会いの手配
- 女性紹介
- 店外サービス
- 価格交渉
- 同伴者手配
- 性的サービス案内

15.2 ドライバーの役割
可能:
- 空港送迎
- ホテル送迎
- 観光地送迎
- 郊外移動
- 待機
- 一般的なエリア説明
- レストラン・観光地の一般情報

不可:
- 女性紹介
- 違法サービス紹介
- 性的サービス交渉
- 違法な店舗への誘導
- 違法行為のサポート

15.3 免責事項
- 天候
- 交通渋滞
- フライト遅延
- アクティビティ中止
- ドライバーの急病
- 店舗営業変更
- 利用者の飲酒
- 個人間トラブル
- 利用者の違法行為
- 第三者事業者のサービス品質

15.4 法務確認が必要な項目
- 日本の旅行業法
- フィリピンの観光事業規制
- 有償送迎・車両営業許可
- ドライバー紹介手数料（将来検討。初期MVPでは対象外）
- 決済代行
- 旅行者保護
- 保険
- 越境個人情報
- 日本・フィリピン双方の税務

18. 技術構成案
==================================================

シンプル構成:
- Frontend: Next.js
- Backend: Next.js API Routes または NestJS
- DB: PostgreSQL
- ORM: Prisma
- Auth: NextAuth/Auth.js
- CMS: Sanity / Strapi / Headless WordPress
- Hosting: Vercel + Supabase / AWS
- File Storage: S3
- Email: Resend / SendGrid
- Payment: Stripe
- Monitoring: Sentry
- Analytics: GA4 / PostHog
- Calendar: Google Calendar連携
- Video Meeting: Zoom URL手動登録またはGoogle Meet

代替構成:
- Laravel + PostgreSQL + AWS
- Django + React
- Supabase中心のサーバレス構成
