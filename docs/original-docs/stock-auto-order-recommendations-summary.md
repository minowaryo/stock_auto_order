## 結論（3行）

1. **シグナルの精緻化からは、もうほとんど成果が出ない。** 数学的な理由があり、努力量の問題ではない
2. **価値があるのは「どれだけ買うか」の管理と、シグナルの検証機構。** どちらも現在ゼロ
3. **1箇所、系統的に逆を向いている判定がある**（PEGの高成長側）。半導体集中という実態に直撃する

## 核心: なぜ銘柄選択では勝てないのか

半導体・AI銘柄は互いに強く相関している（平均相関0.6〜0.7）。主成分分析では第1主成分だけで分散の60〜75%を説明してしまう。

つまり **50銘柄を保有していても、リスクの観点では実質2〜5本のベット**しか持っていない。

運用の基本式に入れると:

```
IR ≈ IC × √(実効ベット数)
   ≈ 0.05 × √4
   ≈ 0.10        → 年次では統計的にゼロと区別できない
```

IC=0.05は優秀な水準。それでもこの結果になる。**7つの利確シグナルと8つの買いシグナルをどれだけ磨いても、ここから取り出せるアルファはほぼない。**

一方、半導体セクターが30%下落すれば保有10銘柄すべてが25〜35%下がる。銘柄分散は効かない。しかし**事前に比率を60%→30%へ落としていれば、資産全体で約9%を守れる。** これは銘柄選択で狙えるどんなアルファよりも桁が大きい。

**成績を決めるのは「どれを持つか」ではなく「どれだけ持つか」。**

## 今すぐ直すべき1件: PEGの山側

ADR-0015 D3は「低成長（5%以下）の銘柄でPEG判定を無効化」した。これは**谷側・成熟企業側の是正**であり正しい。しかし**高成長側の判定（閾値1.0/2.0）は不変**のまま残っている。

半導体株で何が起きるか:

| 局面 | 利益 | PER | 成長率 | 判定結果 |
|---|---|---|---|---|
| **サイクルの山** | 最大 | 低い（Eが膨張） | 高い | PEG≈0.3 → **`peg_undervalued`発火 → 天井で買い増し候補** |
| **サイクルの谷** | 崩壊 | 高い | マイナス | 低成長でPEG除外 → 代替条件（PER≤15かつ配当≥3%）に半導体は該当せず → **沈黙。買い場を逃す** |

**天井で買いシグナルが出て、底では何も出ない。** シクリカル銘柄に対して系統的に逆を向いている。

対処は軽量（成長率が異常に高い場合もPEG判定から除外する等、D3と同型の条件追加）。

## やらない方がよいこと

| 項目 | 理由 |
|---|---|
| **CHG-0017系の「対市場13週相対リターン」を序列に使う** | 横断面モメンタムは日本で機能しない（単独Sharpe 0.03）。さらに同一業種内での相対強度は米国でも残らない（個別モメンタム利益の60〜73%は業種モメンタムで説明される） |
| **50銘柄の総合スコア・ランキング** | 実効ベット数が足りずノイズになる |
| **RSI/MACDの売買シグナル化を深掘りする** | 3か月〜1年保有と時間軸が合わない。表示に留めるのが妥当 |
| **注目テーマを加点として使う** | テーマ型は設定後5年でリスク調整後 約-30%。かつ「AI・半導体偏重を是正する」という当初課題と逆方向に働く。**集中の警告として使うなら整合する** |
| **多因子モデルの最適化** | この規模では過学習が確実 |

## 目標定義の見直し

現在 `BACKGROUND.md` は年率+5%を「**最低限確保したい下限ライン**」とし、「現金ベースの年間利益額 約100万円以上」と定義している。2点、問題がある。

1. **+5%は下限ではなく上限寄り。** 体系的な銘柄選定で現実的に期待できるのは年3〜8%。下限に置くと、届かない年に「システムが悪い」と誤診してルールを弄る圧力になる（実質的な過学習）
2. **現金ベースの利益額では、勝ち銘柄を売るだけで達成できてしまう。** アルファの測定になっていない

**推奨**: 下限→目標へ格下げし、**同額を何もせず持ち続けた場合（ガチホ）との差**で定義する。年次の当たり外れ幅（例: -5%〜+12%）も併記する。

## 既に正しく判断されていた点

独立に同じ結論へ到達している箇所が複数ある。設計判断の質は高い。

- **ADR-0015 D3**（低成長銘柄のPEG無効化）— PEGのシクリカル機能不全を自力で発見
- **ADR-0015 D5**（週足MA75の傾き条件）— これは時系列モメンタムそのもので、証拠が強い手法
- **ADR-0016**（PER≤15シグナル）— バリューは日本で最も頑健な要因
- **ADR-0015改訂**（業種名からの機械分類を自ら棄却）— 実データ7/146で判断
- **ADR-0016の会計恒等式による論証**（PBR≈PER×ROEゆえROE≥10%とPBR≤1.0は両立しない）
- **合成スコアをF-009に限定し、他は透明なマルチキーソート** — 過学習の入口を意図的に塞いでいる
- **実装前に実データで検証する運用**（保有219銘柄で実測し当初案を破棄）
