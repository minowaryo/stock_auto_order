# 株式ポートフォリオ管理システム 設計プラン

## 背景・目的
- 楽天証券で中長期(3ヶ月〜1年程度)を基本とした株式投資を行っている
- 現状は「メタトレンドで上昇傾向にある市場・銘柄」を選んで投資する流れはうまくいっているが、利益確定のタイミングに規律がなく、年間の利益率を伸ばしきれていない
- 目的は以下3点をシステム化すること
  1. 保有銘柄の売買タイミング判断(利益確定の規律を含む)
  2. ポートフォリオのリバランス(セクター偏りの是正)
  3. 新規投資先(市場・銘柄)の選定支援

## 現状の保有・課題
- ファナック、キオクシア、村田製作所を買い増し検討中
- 現在の保有がAI・フィジカルAI・半導体関連に偏っており、他セクターを20〜30%程度持つ形に分散したい
- 注力銘柄は5〜10銘柄程度に絞って運用する方針
- 楽天証券のCSVエクスポートを月1〜2回のペースで取り込む想定(CSV自体は未取得、後日用意)

## 実装方針
- **Claude Codeでローカル/自動実行のパイプラインとして構築**(Artifactのブラウザサンドボックスは外部API連携に制約が多いため不採用)
- 将来的にCSV投入→指標計算→レポート生成を定期実行できる形を目指す

## 分析の2本柱

### 1. テクニカル指標(売買タイミング)
- RSI(14期間)
- MACD(12/26/9)
- ボリンジャーバンド(±2σ)
- 移動平均線(MA20/MA75)、ゴールデンクロス/デッドクロス
- 直近値動きが大きい3〜5銘柄を自動ハイライトし、次の判断ポイントを提示

### 2. ファンダメンタルズ指標(保有継続の妥当性)
- PER・PBR(割高/割安)
- ROE(資本効率)
- 売上高・営業利益成長率(直近数四半期)
- 自己資本比率(財務健全性)
- 配当利回り・配当性向
- データ取得元候補: J-Quants、EDINET(有価証券報告書)、証券会社スクリーニングデータ

## 売買ルール設計方針
- 固定ルールではなく、銘柄ごとに指標を根拠として個別に判断する設計
- **対象範囲は「含み益が一定水準(例: +20%)を超えた銘柄」の"ラストワンマイル"利確判断に絞る**(含み益が薄い/マイナスの銘柄や新規買いは対象外とし、引き続き人力判断)
- 運用サイクル: 週末にCSVをアップロード→分析→月曜寄り付き前などに指値を設定、というリズムを想定(日次で相場に張り付かない前提)
- 「全部売る/全部持つ」の二択ではなく、分割指値(例: +20%地点で1/3、+35%地点で1/3、残りはトレンド追従)を基本形とする
- 利益確定シグナル例:
  - 含み益が一定水準に到達
  - RSIが高水準から反落し始めた
  - MACDデッドクロス発生(トレンド終了サイン)
- 週次スナップショットのため、決算発表等のイベントで想定と乖離した価格でギャップアップ/ダウンし、指値が想定通り約定しないリスクがある点は運用上の注意点として認識
- 将来的に過去の売買を振り返るバックテスト機能を追加し、ルール自体の精度を検証・改善する

## ポートフォリオ・リバランス機能
- 保有銘柄をセクター別に集計
- AI/半導体等への偏り(70〜80%超など)を検出したら、他セクターの具体的候補銘柄とともに提案

## 市場・銘柄選定機能
- メタトレンド(上昇傾向にある市場・セクター)の予測・選定自体は本人が人力で判断する方針
- システム側の役割は選定支援というより「分類・可視化」に重点を置く
  - 保有銘柄をカテゴリ(セクター・業種)別に自動分類
  - 分散投資の観点で、どのカテゴリにどれだけ配分されているかを可視化
  - 人力で選んだ新規投資候補についても、既存カテゴリとの重複/分散への影響を判定できると良い

## データソース(調査結果反映)
- **日本株セクター分類・ファンダメンタルズ: J-Quants API(無料プラン)**
  - JPX公式。`listed/info`で銘柄コードから17業種コード/33業種コードが取得可能(全銘柄で取得率100%) → 保有銘柄のカテゴリ分類に使える
  - 財務諸表(損益計算書・貸借対照表・CF)、配当情報も取得可能
  - 注意点: 無料プランはデータが12週間遅延するため、**直近の値動き(テクニカル指標用の日足)には不向き**。業種分類・ファンダメンタルズ用途に限定して使う
- **日本株の直近株価・テクニカル指標: Yahoo Finance非公式API等、遅延のないソースを別途使用**(Claude Code経由でのアクセスを想定)
- **米国株のセクター分類・株価・ファンダメンタルズ: yfinance(Yahoo Finance非公式ライブラリ)**
  - `info.get('sector')` / `info.get('industry')`でGICSベースの分類を遅延なく取得可能
  - PER/PBR/ROE等の主要ファンダメンタルズ指標、株価履歴も取得可能
- 保有データ: 楽天証券CSVエクスポート(国内株式・米国株式・投資信託、それぞれ別ファイル。Shift-JISエンコード、数値はカンマ区切り文字列でクォート付き)
