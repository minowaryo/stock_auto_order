# CHG-0031 Gate 1 要件変更草案: 市場からの調査候補発見

> 状態: 2026-10-03本人承認、2026-10-04に[requirements.md](requirements.md)へF-016として反映済み。**Gate 1／2承認済み、Gate 3／4未承認**。承認時の差分案として本文を保持する。4週後の品質再精査は[PLAN](../../PLAN.md)の継続課題。本人指示により今回のモックは省略し、[UC-016](use-cases.md#uc-016-市場からの調査候補発見確認)の本文でGate 2をレビューし、2026-10-04に本人承認済み。情報源の採否は[試行](../investment-research/megatrend/source-pilot-log.md)後に判断する。

## 変更する目的と範囲

現行[UC-012](use-cases.md)は、楽天証券のお気に入りCSVから取り込んだ未保有銘柄を分析する。これでは、市場の一次情報や専門家の公開発信を起点に、**お気に入りCSVにもアプリのウォッチリストにもない企業**を見つけられない。CHG-0031では日本株・米国株の未登録企業を「調査候補」として発見する機能を追加し、本人が証拠を確認してから監視対象に選ぶ。既存の売買シグナルや購入判断とは接続しない。

本人が扱うメガトレンドを対象とし、初期の検討領域は半導体・AI基盤（電源・冷却を含む）、フィジカルAI・産業ロボット、医療AIとする。電力・蓄電など他の領域へ広げられるよう、特定の情報源や固定キーワードに要件を依存させない。テーマ自体の将来予測や「有望銘柄」の自動判定はこの変更の対象外とする。

## `requirements.md`へ反映する要件案

### 1章・2章 INへの追加

- **F-016（提案） 市場情報からの未登録上場企業の調査候補発見**: 本人が指定するメガトレンドについて、取得条件を確認した無料の公開情報を入口に、既存のお気に入りCSV・ウォッチリストにない日本・米国の上場企業を調査候補として提示する。登録済み・保有済みの企業は区別して表示し、新規発見数に加えない。候補を売買推奨とは扱わない。
- 発見経路は、取得を認められた公式の機械可読データ・配布ファイル等の定期確認と、専門家記事・公開動画・SNS・企業開示等のURLを本人が手動で記録する経路を区別する。**定期取得する具体的な情報源、取得頻度、無料枠、実装順は4週間の試行と利用条件の確認後にGate 2以降で確定**する。取得可能な源がなければ、当該源の自動取得を実装対象に含めない。
- 調査候補には、テーマと企業の関係、元の出来事を発表した主体、元資料URL、元発表日、確認日、発見経路、企業の役割、上場主体と市場・銘柄コードの確認根拠、採択・製品・導入・受注・売上など証拠の段階、反証・未確認事項を残す。同じ元発表を複数媒体が紹介しても1件として扱い、異なる元発表だけを別の証拠とする。
- 法人・上場親会社・銘柄コードが曖昧な企業は「同定保留」として記録できるが、確認済みの上場銘柄数に加えない。子会社、同名企業、非上場、上場廃止、ティッカー変更の疑いがあれば人手確認へ回す。
- 候補のウォッチリスト・保有状況は、参照したデータの時点とともに示す。データが古い、元資料が取得できない、情報源の更新が止まった場合は「未確認／欠測」を表示し、古い発表を今週の新着と誤表示しない。
- 対象テーマ・市場・確認した情報源・最終確認時刻を示し、未確認の情報源や対象外の範囲を分かるようにする。候補が0件でも、市場全体に該当企業がないという意味には扱わない。
- 本人が上場主体・元資料・反証を確認し「監視する」と選ぶまで、候補を既存の`watchlist_items`、`holdings`、売買シグナルに自動登録しない。UC-012へ渡す操作と入口（お気に入りCSV経由または新しい直接登録）はGate 2で明示する。

### 2章 OUTの改訂案

現行の「メタトレンド自体の自動発見・予測・選定」を対象外とする記述は、**将来のトレンドや銘柄の有望性を機械的に予測・採点しない**という意味に限定する。F-016の「公開された出来事から上場企業を調査候補として拾い、証拠とともに提示する」はINとする。SNSの拡散数や専門家の評価を投資スコアにすること、出典のない自動銘柄フラグ付け、投資順位付け、自動売買はOUTに残す。

## 4週間の情報源試行後に再精査するメモ（2026-10-03本人指示）

**情報源の正確さ・裏付けやすさを実測し、その結果を受けて本草案の要件も再精査する。** Gate 1の審議は先行できるが、草案の内容を試行結果にかかわらず固定しない。このメモ自体をGate 1の承認記録とは扱わない。

- 見直し時期: 試行期間2026-10-05〜11-01の終了後、2026-11-02以降を目安に実施する。4週分の記録が欠けていれば未実施・欠測を明示し、日付の経過だけで検証済みにしない。
- 確認する根拠: [試行ログ](../investment-research/megatrend/source-pilot-log.md#4週後の見直し)と調査カード。情報源の主張と一次資料の一致・不一致、訂正、企業・親会社・ティッカー・日付の誤り、転載の重複、未確認事項を源ごとに確認する。一次資料へ到達しただけで主張全体を正しいと扱わず、情報源側の誤りと調査時の読み違いを区別する。
- 実用性の確認: 未登録企業の発見数、テーマ・市場の偏り、更新頻度・遅延、確認時間、無料で継続取得できる条件も合わせて評価する。4週間では長期予測の的中率や投資成果は判定しない。
- 要件への反映: 対象テーマ、発見経路、必須の証拠・同定・鮮度表示、本人確認とUC-012への受け渡し条件を、実際に得られた情報で満たせるか見直す。各項目を「維持／修正／保留」とし、根拠カード、修正理由、未解決事項を残す。自動取得対象・頻度は源ごとの採否結果から具体化する。
- 再開時の手順: 試行ログの集計 → 情報源ごとの採否判断 → 本草案との差分提示 → 必要な要件・UCの再レビュー。先にGate 1を承認していた場合も、範囲変更があればCHG-0031の変更追跡に残し再承認を得る。
