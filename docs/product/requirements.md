## 1. 背景・目的

日本人旅行者、特に30代前半〜50代前半の男性を主な対象に、フィリピン（マニラ・クラーク・アンヘレス周辺）への旅行に対する不安を解消するための旅行前相談・現地情報提供サービスをWebで展開する。

集客はSNS（YouTube/X/Instagram/TikTok）による認知拡大とSEO記事による検索流入を前提とし、Webサイトは「SNSで興味を持った見込み客の受け皿」として、深い情報提供とZoom相談へのコンバージョンを担う（一次資料 0節）。

初期MVPでは、画一的なパッケージツアーではなく、Grabの利用支援を軸にした「旅行者自身が安全に動けるようになる」情報提供と、旅行者の体力・興味・予算に応じた柔軟な旅程提案によって差別化する。ドライバー紹介・予約・決済・チャット・ユーザーアカウントは、需要と法務条件（日本の旅行業法、フィリピンの有償送迎規制等）が確認できるまで対象外とする（一次資料 1.3〜1.5節、15.4節）。

## 2. スコープ

### IN（Phase 1 / MVP対象）
- 公開サイト（トップ、サービス概要、料金、モデルプラン、アクティビティ一覧・詳細、旅行記事一覧・詳細、ドライバー紹介サービス説明、FAQ、利用規約、免責事項、プライバシーポリシー、問い合わせ）
- 旅行相談申込（Zoom相談申込 + 事前アンケート + 利用規約/免責同意）
- 問い合わせフォーム
- 管理画面（相談・顧客一覧、事前アンケート閲覧、相談ステータス管理、旅行プラン作成・編集、アクティビティ管理、コンテンツ（記事）管理、FAQ管理、簡易売上管理、同意・監査ログ）
- 申込完了メール通知
- プレミアムプラン限定のオンサイトサポート（旅行中、管理者へ電話/LINE等で直接連絡できる**運用上の**個別連絡対応。アプリ内チャットや自動応答等のシステム機能は伴わない。連絡先は旅行プラン共有時にあわせて案内する）

### OUT（Phase 1 対象外。Phase 2/3で再検討）
- ユーザーアカウント登録・ログイン・マイページ
- 決済機能（オンライン決済）
- 滞在中チャットサポート（アプリ内チャット等のシステム機能。プレミアムプランの電話/LINE個別連絡対応とは別物で、そちらはIN対象）
- レビュー・紹介コード機能
- ドライバー紹介・予約・自動マッチング・ドライバー専用ポータル
- ドライバー候補の簡易台帳・評価メモ（管理者専用・内部限定機能含む。Phase 1では見送り、Phase以降で再検討）
- 多言語対応、LINE/WhatsApp**システム連携**（API連携・自動通知等）、位置情報、緊急連絡の自動化

### 恒久的対象外（Phaseによらず提供しない）
- 女性の紹介、性的サービスの斡旋・価格交渉
- 店舗との交渉代行、違法サービスの予約・手配
- 無許可・無保険の有償送迎の紹介
- 法令上旅行業登録等が必要な旅行商品の包括販売（事業形態確定前）

（一次資料 1.4節・15.1〜15.2節を参照。詳細な禁止表現・境界線は `docs/ai-context/do-not-touch.md` にも反映済み）

## 3. Actor（利用者）

| Actor | 説明 | 権限レベル |
|---|---|---|
| 管理者 | 事業者本人。相談・顧客・コンテンツ・プラン・売上を管理 | 最高権限（Sanctum認証 + Policy/Gate） |
| サイト訪問者（見込み客） | 会員登録なしで公開サイトを閲覧し、相談・問い合わせを行う一般利用者。Phase 1ではアカウントを持たない | 匿名（フォーム送信のみ） |

> Phase 1には「一般ユーザー」としての認証済みActorは存在しない。事前アンケート・相談申込はメールアドレス等の入力のみで完結する。

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 可用性 | MVP期間: 月間99.5%稼働目標（一次資料14.2節） |
| パフォーマンス | 主要ページ3秒以内表示。画像最適化・CDN・DBインデックスで担保 |
| セキュリティ | HTTPS必須、管理画面はSanctum認証＋Policy/Gateによる認可、CSRF/XSS/SQLi対策（OWASP Top 10準拠）、監査ログ、ログイン試行制限、APIレート制限 |
| モバイル対応 | スマートフォン最優先、日本語UI。英語切替・LINE/WhatsApp導線はPhase以降 |
| プライバシー | 必要最小限の個人情報収集。ナイトライフ関心等の任意項目は必須化しない。旅行目的等を第三者へ不要に共有しない。削除依頼への対応手順を用意 |
| SEO | SEOフレンドリーURL、sitemap.xml、robots.txt、OGP、構造化データ、メタタグ管理（一次資料0.5節） |
| データ保持 | 事前アンケート・相談記録・同意記録等のPIIは、サービス利用（相談完了または最終問い合わせ）後1年保持し、その後削除する |

## 6. 制約・前提

- 自社車両は保有せず、Grabを標準の移動手段として案内する（ドライバー紹介はPhase 1で提供しない）
- 初期はクラーク・アンヘレスエリアを中心とし、アンヘレス4泊5日プランを主力コンテンツとする
- 技術スタックはADRにより確定済み: Laravel + MySQL + Vue3/Inertia.js/Pinia + Sanctum（[[ADR-0001-use-laravel]] [[ADR-0002-use-mysql]] [[ADR-0005-frontend-stack]] [[ADR-0003-auth-strategy]]）。一次資料内のNext.js/PostgreSQL/Prisma案は不採用
- ドライバー紹介手数料・有償送迎の法的位置づけ等、法務確認が必要な項目（一次資料15.4節）はPhase 1のスコープに含めない
- サイト上の表現は一次資料15.1節の「推奨/避ける」表現ガイドラインに従う

## 7. 料金

| プラン | 料金 | 備考 |
|---|---|---|
| ライト相談 | 5,000円 | 30分Zoom相談 |
| スタンダード | 25,000円 | 標準的な旅程相談・プラン提案を含む |
| プレミアム | 40,000円 | 60分相談・詳細な旅程プラン作成に加え、旅行中のオンサイトサポート（電話/LINE等での個別連絡対応、運用ベース）を含む |

- アクティビティ費用は実費（本サービスの料金には含まない）
- ドライバー費用: Phase 1では対象外（サービス自体を提供しないため発生しない）
- プレミアムのオンサイトサポートはアプリ内チャット等のシステム機能を伴わない、電話/LINE等による運用上の連絡対応であり、追加のシステム開発を要しない
- 滞在中チャットサポート（システム機能としてのチャット）等のオプション料金は今後追加検討（Phase 2以降）
