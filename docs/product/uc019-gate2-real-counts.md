# UC-019 Gate 2 判断材料: 段階3の実件数（2026-10-19）

UC-019（売買時の状況別の振り返り）のGate 2は「段階3の実件数（クラスタ数・結果待ち・算出不可）を見てから承認する」と決めている（2026-10-04）。その実件数をまとめる。承認記録ではなく、判断材料である。

## 計測方法

- 開発DBを読み取りのみで集計（アプリコードは変更していない。コードは公開中の`d932121`）。
- 対象は売買（`buy`/`sell`）のうち定型（`is_routine`）を除いたもの。件数は売買1件×評価期間ごと。
- クラスタは[UC草案](trade-decision-effect-gate2-uc-draft.md)の定義（同日・同銘柄・同方向を1件にまとめ、同じ銘柄で+26週が重なる売買を連鎖して1クラスタ）。市場別の集計で、結果の有無は問わない近似。

## 読み取れること（提案）

1. **条件別に切ると1セルあたりのクラスタ数は少なくなる。** 売却全体で124クラスタ・買付で184クラスタ、これを市場・状況区分・評価期間で分けると、草案の将来の判定基準（30件／3暦年）に届くセルはほとんどない。初期画面は「探索的結果」に限る方針（草案どおり）で妥当。
2. **当時記録の状況は87件のみ。** 事後再計算（価格系指標）を実装しない限り、状況別の画面は大半の売買が「状況不明」になる。段階として事後再計算を含めるかを決める必要がある。
3. **3暦年の基準は2024〜2026の3年のみ満たせる。** 2022年は3件で実質使えない。

## Gate 2で決める事項（本人）

- 30件／3暦年の最低条件を将来の仮説判定に採用するか（草案の未決事項4）。
- 承認の場合、`use-cases.md`の承認記録へ追記し、Gate 4（テストケース承認）のRedへ進む。
