## 市場からの調査候補（UC-016）

「新規投資候補」の「調査候補」で、公開資料から見つけた企業を手動で記録します。未登録企業や銘柄コードが分からない企業も保存できます。資料のURL、発行者、確認日、自分の要約、企業とテーマの関係を入力してください。記事や動画は発見の入口であり、元発表と上場主体は別途確認します。

候補の「訂正」で元資料、上場確認元、主張と根拠、反証・未確認事項を追記します。複数の主張や上場先がある場合は「主張を追加」「上場先を追加」で別の版として記録し、追加した行も選んで訂正できます。未確認の主張は、確認日を空欄のまま追加・訂正できます。元発表URLを変えると元発表の確認状態と旧確認日が消え、旧URLを根拠とする主張も未確認へ戻ります。変更後のURLを確かめてから、別の訂正操作で元発表を再確認してください。再確認までは監視に追加できません。保留・見送りは理由を記録します。同じ元発表の転載は、元発表IDを確認して関連付けます。記録時に同じURLや同名法人が見つかった場合は「この元発表に関連付ける」「この法人に関連付ける」で選べます。銘柄コードは日本株4桁（例: 7203、523A）、米国株はティッカー（例: NVDA）で入力し、「.T」等の取引所接尾辞は付けません。一覧の「照合結果」は、最新の保有スナップショットとウォッチリストとの現在の照合（保有中／ウォッチリスト登録済み／★なし／未登録／照合未実施）です。誤って関連付けた場合は詳細から解除できます。「詳細・履歴」では訂正前後の内容を確認できます。

「監視に追加」では、確認欄に表示された銘柄、元資料、主張、反証、直近の保有・お気に入りCSVの照合時点を確認し、理由を入力して確定します。確認事項や照合元が欠けると登録は保留されます。既存のウォッチリスト行がある場合は★やフォルダ、メモを上書きしません。保有済みならウォッチリスト行を新しく作りません。登録後は「ウォッチリスト」で必要に応じて一括更新してください。

### 情報源の確認と候補への記録

アプリ起動時は、価格追跡が終わってから有効な情報源を確認します。同じ源への再確認は、最後の試行から24時間以上（源別設定による）空けます。失敗した試行も間隔の起点です。「情報源の確認状況」で未確認・初回取得・新着あり・新着なし・失敗と確認時刻を確認できます。「今すぐ確認」は有効な源を間隔にかかわらず確認します。

最初に取得した一覧は「初回取得（基準線）」で、新着件数には数えません。「取得した項目」の「候補に記録」でURL・資料名・発行者・紹介元の投稿日をフォームに入れ、テーマ・法人・自分の要約を補って保存します。選択だけでは候補は作られません。公開日不明は空欄のままです。紹介元の投稿日と元発表日は別に確認してください。「対象外」「未処理へ戻す」で項目の状態を切り替えられます。既に記録した候補や関連は保持します。

3回連続の取得失敗では「取得停止中の可能性」、最後の成功確認から配信範囲の目安を超えた場合は「取りこぼしの可能性」と表示します。新着0件だけで欠測なしとは判断できません。初期の自動確認対象は中島聡さんの公開note RSSです。ものづくり太郎のYouTube、NEDO、FDAは自動確認が無効で、引き続き公開サイトを手動確認します（[情報源台帳](megatrend-source-selection.md#起動時確認の登録状態2026-10-11)）。

候補は本人が確認して記録した範囲です。市場全体の網羅や売買の順位付けは行いません。情報源の品質は2026年10月5日から11月1日の試行を記録し、11月2日以降に再評価します。

## 新規投資候補・ウォッチリスト（UC-012）

### この機能でできること

楽天証券のお気に入り銘柄CSVから未保有銘柄を取り込み、指標・押し目買いシグナル・同セクター保有比率を確認できます。画面上の★は、楽天証券側のお気に入りとは別に「継続して監視する銘柄」を示します。

### 操作手順

1. 「新規投資候補」画面で、楽天証券から出力した最新のお気に入り銘柄CSVを取り込みます。
2. 自動更新または「一括更新」が完了するまで待ちます。指標が未取得・更新中の状態では棚卸し判断を確定しません。
3. 継続して確認したい銘柄に★を付けます。
4. 銘柄行を展開し、ウォッチステータスと判断メモを記録します。

### 棚卸しルール

- **月次（軽量確認）**: 月1回を目安に「★のみ表示」で確認します。買い時・次回購入候補などのステータスと、継続監視する理由に変化がないかを見直します。
- **四半期（全件確認）**: 3・6・9・12月末を目安に最新CSVを取り込み、更新完了後に全件を確認します。★付き銘柄には、日付とともに「監視を続ける理由」「想定する保有期間」「前提が崩れる条件」をメモへ追記します。
- **随時確認**: 決算・業績予想の大幅修正、上場廃止・買収など、投資前提を変えるイベントを把握した場合は次回定期日を待たず確認します。
- **★を外す目安**: 継続理由を説明できない、投資テーマから外れた、または分散目的に合わなくなった場合は★を外します。数値条件だけで自動的に外す運用にはしません。
- **履歴の扱い**: ★を外しても銘柄行や過去メモは削除されません。楽天証券側でお気に入り解除済みかつ★なしの銘柄は、監視終了として扱います。

### よくある質問

- **Q. 楽天証券のお気に入りから外したのに一覧に残ります。**

  A. CSV再取込は追加・更新方式で、過去の銘柄を自動削除しません。直近の成功したCSVにない銘柄には「楽天お気に入り解除済」と表示します。必要に応じて画面上の★を外し、過去メモを履歴として残します。

- **Q. 指標が「—」の銘柄は棚卸しで外すべきですか。**

  A. 先に一括更新を実行してください。取得失敗が続く場合も、それだけを理由に自動除外せず、監視理由と利用できる情報を確認して本人が判断します。

- **Q. ★を付けると購入候補に自動決定されますか。**

  A. いいえ。★は継続監視の印です。購入判断は指標、分散への影響、メモなどを確認して本人が行います。

## 売買履歴の取込（UC-017）

### この機能でできること

楽天証券の売買履歴（国内株式・米国株式の全期間）を取り込み、保有CSVと照合します。履歴から数えた株数が、保有CSVの株数と合っているかを確認でき、合わない銘柄が一覧で分かります。売買の成績の計算（今後追加予定）の元データになります。

### 操作手順

1. 「CSV取込」画面の「売買履歴の取込へ」を開きます。
2. 国内株式・米国株式の売買履歴CSV（全期間）を、**両方**選びます。
3. 「プレビュー」で、対象期間と件数（新規・既存・確認待ち・読み飛ばし）を確認します。何も保存されません。
4. 問題なければ「取込を確定」を押します。結果に、照合に使った保有CSVの日付と、一致しなかった銘柄が表示されます。

### 見方

- **新規／既存**：今回初めて取り込んだ行／すでに取り込み済みの行。同じ全期間履歴を何度取り込んでも、行は増えません。
- **確認待ち（前回あって今回ない行）**：前回の履歴にあったのに、今回の履歴にない行です。削除はされず、数え方からは外れます。楽天証券の出力範囲が変わっていないか確認してください。
- **照合の区分**：照合済み（株数が一致）／保有側のみ（保有CSVにだけ株がある）／履歴側のみ（履歴にだけ株が残る）／確認待ち（両方にあるが株数が違う）。
- 照合の相手は、**最新の保有CSV**です。履歴を先に取り込むと、前回の保有CSVが相手になります。保有CSVを取り込んだあとに履歴を取り込むと確実です。
- 約定の時刻はCSVにないため、保有CSVの取込時刻が、約定日の市場の取引終了（国内株15:30東京、米国株16:00ニューヨーク）より後のときだけ、その約定を数えます。

### 注意点

- 履歴は**全期間**を出力して取り込んでください。期間を絞ると、古い行が「確認待ち」になります。
- 投資信託は対象外です。
- 保有CSVがまだ取り込まれていない場合、取込はできますが、照合は行われません。

## 集中度ダッシュボード（UC-015）

### この機能でできること

保有個別株の直近52週の値動きから、「実際にどれだけ一緒に動いているか」を数値で確認できます。業種の比率（セクター配分）では見えない、同じ要因で一緒に上下する偏りを見るための画面です。判定や売買の提案は出しません。

### 操作手順

1. 「セクター配分」画面の上部にある「集中度ダッシュボード」のリンクを開きます。
2. 画面上部で5つの指標と、計算に使った期間・銘柄数・カバー率を確認します。
3. 必要に応じて、相関行列（評価額上位20銘柄）、銘柄別の対SOXベータ、計算対象から外れた銘柄を確認します。

### 指標の見方

- **PC1寄与率**: 保有全体の値動きのうち、単一の共通要因で説明できる割合です。高いほど、1つの要因に依存しています。
- **実効ベット数**: 値動きが実質いくつの独立した賭けに分かれているかを表します。銘柄数が多くても、一緒に動く銘柄ばかりなら小さくなります。
- **対SOXベータ**: 半導体株指数（SOX）が1%動いたとき、保有がおよそ何%動くかの目安です。
- **上位5銘柄ウェイト**: 投資信託・ETFを含む全保有の評価額のうち、上位5銘柄が占める割合です。
- **カバー率**: 計算に使えた個別株の評価額が、全保有に占める割合です。投資信託・ETFは週足を保存していないため計算対象外です。

### 色の見方

- 各指標の横のバッジは、分散が効いているかの目安です。**緑＝分散OK、黄＝やや集中、赤＝集中**です。
- 指標によって良い向きが違います（PC1寄与率・上位5銘柄ウェイト・対SOXベータは低いほど、実効ベット数は高いほど良い）。バッジは向きを揃えて判定しているので、色だけ見れば足ります。
- しきい値は叩き台です。PC1寄与率は25%・45%、実効ベット数は8・3、上位5銘柄ウェイトは30%・50%、対SOXベータ（絶対値）は0.5・0.8が境目です。使いながら見直します。
- 相関行列のマスは、**赤いほど2銘柄が同じ方向に動く**ことを、**緑は逆方向に動く（分散に効く）**ことを表します。色のないマスはほぼ無関係です。
- 判定は画面に表示している桁の値で行います（25.0%と表示されていれば「やや集中」です）。
- 総合点や順位は出しません。指標ごとの色を見比べてください。
- 「セクター配分」画面と「集中度」画面は、タイトルの下の切替で行き来できます。

### 注意点

- リターンは各銘柄の現地通貨建て（米国株はドル建て）で、為替の影響は含みません。
- 計算対象の銘柄数が52（週数）を上回るとき、相関・PC1寄与率・実効ベット数は推定の誤差が大きくなります。画面に注記が出るので、目安として見てください。
- 「取得不可（—）」はSOX指数の週足が取れていないとき、相関行列の「—」は値動きが全くない銘柄との組です。「算出不可」は計算対象が2銘柄未満のときに出ます。
- 値はCSV取込で保存された週足から毎回計算します。取込前など週足がそろっていないときは算出できません。

## シグナル検証（UC-014）

### この機能でできること

売買シグナル（利確検討・買い増し・ウォッチリストの押し目買い）が出た後、その銘柄が実際に市場（日本株は日経平均、米国株はS&P500）より良かったか悪かったかを、+4週・+13週・+26週の「超過リターン」で確認できます。閾値（RSI70・PER15など）を変えるかどうか迷ったときに、「今のルールで出たシグナルは実際に効いていたか」を実測で確かめるための画面です。この画面の結果で閾値や判定が自動で変わることはありません。

### 操作手順

1. 「売買シグナル」画面のタイトルの下にある「シグナル検証」タブを開きます（戻るときは「売買シグナル」タブ）。
2. 必要に応じて、発生元（利確検討／買い増し／ウォッチリスト押し目買い）と市場（日本株／米国株）で絞り込みます。
3. シグナル種別ごとに、評価期間別の平均超過リターン・中央値・t値・的中率・判定を確認します。
4. 「個別の発生を表示」を開くと、銘柄・発生週・各期間の超過リターンと、発生時点の根拠値（RSI・PERなど）を新しい順に確認できます。

### 見方

- **超過リターン**: 銘柄の騰落率から、同じ期間の指数の騰落率を引いた値です（配当を含まない価格ベース）。買い系はプラス、利確系はマイナス（売った後に市場を下回った＝売って正解）が期待どおりです。
- **結果到来「30件（1週）」**: 結果が出た発生の件数と、その発生週の数です。同じ週に出たシグナルは同じ相場に一緒に左右されるため、平均・t値・判定は**同じ週の発生を1件として**計算します。中央値・的中率は個々の発生の値です。
- **判定**: 機能している（期待どおりの向きで、t値の絶対値が2.0超）／機能していない（逆向きで有意）／判断保留／異常を疑う（効果が大きすぎる。成功ではなくデータ不備を疑う）。3年たまるまでは「機能している」に「（暫定）」が付きます。
- **判定に必要な量**: 結果が30件以上、かつ発生週が評価期間の3倍以上（+4週は13週、+13週は39週、+26週は78週）。それまでは「判断保留」です。+26週の判定が出るのは早くても約2年後で、それが正しい見え方です。
- 「結果待ち」は評価期間がまだ経過していない発生、「算出不可」は週足や指数が欠けて計算できない発生で、どちらも集計から除きます。導入前に移送した発生は、根拠値が「記録なし」になります。

### 注意点

- +13週・+26週は、続けて出た週どうしで評価期間が重なるため、判定は控えめに読んでください。
- 閾値を変えるかどうかは、判定だけでなく個別の発生も見たうえで、別途判断します。

## 売買の振り返り（UC-018）

自分の実際の売買が、何もしない（持ち続ける）より良かったか、株式部分が年20%・25%の目標に届いたかを見る画面です。売買履歴の取込（UC-017）を済ませてから使います。手で入力するものはありません。

- 開き方: 「売買シグナル」画面の上の切替タブ「売買シグナル｜シグナル検証｜売買の振り返り」から開きます（`/trade-review`）。
- 「成績」タブ: 直近52週と暦年ごとに、国内株・米国株の株式部分（配当除く。投信・現金は含まない）の年率、ずっと持ち続けた場合、その差、判定（20%未達／20%達成・25%未達／25%達成）を出します。1年に満たない期間は「参考」、株価の取れない銘柄が評価額の5%を超える期間は「判定保留」です。
- 「売買一覧」タブ: 売却・買付ごとに、+4週・+13週・+26週の差を、元の金額に対する%で出します。プラスなら売買した方が良かったことを表します。
  - 売却単独: 売った代金を現金のまま持った場合と、持ち続けた場合の差。
  - 乗換え（参考）: 売却から5営業日以内の同じ市場の買付に、売却代金を充てたとみなした場合の差。
  - 比例買増し: 買付のうち新規資金の部分を、前週末の保有構成どおりに買い増した場合との差。「指数（参考）」は日経225／S&P500との差です。売却代金ですべて賄われた買付は「売却代金を充当（乗換え側で評価）」と出ます。
  - 評価週がまだ来ていないものは「結果待ち」、株価がないものは「算出不可」です。
  - 直前の状況: 売買の直前に記録されていたシグナルと、前週末の保有割合を出します。売買の理由とは限りません。記録がなければ「状況不明」です（記録は2026年8月下旬から）。
- 表示は、取込や起動時の株価追跡のあとに裏で計算し直しておくので、ふだんは待たずに開けます。

## 割安・割高と財務の色（UC-002・UC-003・UC-004・UC-010・UC-011・UC-012・UC-013）

### この機能でできること

PER・PBRが、その銘柄の業種の標準と比べて割安か割高かを、色とラベルで確認できます。ROE・自己資本比率・営業利益率・成長率は、良好かどうかに加えて、とくに優れている（強い良好）ものを濃い緑で示します。

### どこに出るか

- 保有一覧: PERバッジと売上成長バッジ
- 銘柄詳細: PER・PBRの判定と、業種の基準値・基準比・基準日・出典。ROE・自己資本比率・営業利益率・売上成長率のバッジ
- 売買シグナル画面（利確検討・買い増し候補・キープ）と新規投資候補: 判定チェックリストのPER・PBRチップと財務チップ
- 整理検討（含み損）の表: 色は付けず、「割安」などの文字だけを出します

### 色の見方

| 表示 | 意味（業種の基準値との比率） | 色 |
|---|---|---|
| 強い割安 | 0.50倍未満 | 濃い緑 |
| 割安 | 0.50倍以上0.80倍未満 | 緑 |
| 並み | 0.80倍以上1.25倍以下 | 色なし |
| 割高 | 1.25倍超2.00倍以下 | 黄 |
| 強い割高 | 2.00倍超 | 濃いオレンジ |

- 基準値は、日本株がJPXの業種別の単純平均（業種の典型的な1社の水準）、米国株が Damodaran と SPDR 業種ETFの平均です。値と出典は `docs/product/valuation-benchmarks.md` にあります。
- 基準が不安定な業種では、濃い色を使わず「基準が不安定」と表示します。
- 業種が未分類の銘柄や、赤字でPERが0以下の銘柄には、色を付けません（銘柄詳細では理由を表示します）。
- 財務の「強い良好」のラインは、日本株と米国株で違います（例: ROEは日本株15%以上、米国株25%以上）。

### 買い増し判定への影響

買い増しシグナルのうち、PERによる割安の判定は、業種の基準値との比率で行います（信頼度が高い業種は0.80倍未満、基準が不安定な業種は0.70倍未満）。業種が分からない銘柄だけ、従来どおり PER 15倍以下で判定します。買い増し候補と新規投資候補のPERチップには、「≤18.0（業種基準22.5の0.8倍）」のように、その銘柄に使った基準が出ます。

### 注意点

- 色は判断の目安です。財務健全性の判定や利確の判定には使っていません。
- 基準値は、日本株は月に1回、米国株は年に1回（1月）更新します。銘柄詳細の基準日で、いつの値かを確認できます。
