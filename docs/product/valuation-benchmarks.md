# 業種別PER/PBR基準値（割安・割高の色付け用）

> CHG-0034 / ADR-0023 の基準値の正本。値・出典・基準日・信頼度はこのファイルで管理し、実装時に `config/valuation_benchmarks.php` へ同じ内容を写す。
> 値は叩き台。使いながら調整する（ADR-0021 のしきい値と同じ扱い）。変更するときはこの表を先に更新する。
> 調査日: 2026-10-03。調査は5つのサブエージェントが一次資料から行った。**元の取得結果は [`valuation-benchmarks-evidence/`](valuation-benchmarks-evidence/) に残してある。主要な値は、実装前に公式ページで目視確認する**（ETF側の値は要約経由で取得したため）。

## 1. 基準値の決め方

| 項目 | 日本株 | 米国株 |
|---|---|---|
| 主な出典 | JPX（日本取引所グループ）「PER・PBR（規模別・業種別）」月次統計、プライム・連結、基準日 2026-09末 | Damodaran（NYU Stern）業種別データ、基準日 2026-01-05 |
| 照合 | JPX TOPIX-17 指数ファクトシート（基準日 2026-08-31） | SPDR 業種ETF（等ウェイト系、基準日 2026-10-01） |
| 定義 | 実績ベース（予想ではない）。時価総額加重（株価合計÷EPS合計、PBRは純資産合計） | 黒字企業のみの集計PER（時価総額合計÷TTM純利益合計） |
| アプリ側の値 | PER=現在値÷直近開示EPS（実績）。定義はおおむね揃う | PER=Finnhub `peTTM`（実績）。定義はおおむね揃う |
| 基準値 | 直近値（17業種は33業種の公式値を純利益・純資産で加重集計した再計算値） | Damodaran の業種代表値と SPDR ETF 実績P/Eの相加平均 |
| 更新 | 月次（四半期ごとに見直しでも可） | 年1回（Damodaran の更新は毎年1月） |

民間サイト（株探・IFIS・edinetty・kinmyakucode）は基準値に使わない。定義（予想か実績か、単純平均か中央値か）で値が2〜5倍ずれるため（小売PER: 10.3〜36.0）。JPX の値が異常でないかの確認だけに使った。

## 2. 信頼度の決め方

| 信頼度 | 条件 | 画面での扱い |
|---|---|---|
| `high` | 日本株: 直近12か月のレンジ幅（最大÷最小）が1.4未満で、構成銘柄が25社以上。米国株: Damodaran とETFの値の差（最大÷最小）が1.25以下で、業種対応が明確 | 5段階（濃い色を含む）で判定する |
| `medium` | 日本株: レンジ幅が1.4以上1.5未満、または構成銘柄が10〜24社。米国株: 差が1.25超1.5以下 | 通常の色（濃い色は使わない）で判定する |
| `low` | 日本株: レンジ幅が1.5以上、または構成銘柄が10社未満。米国株: 差が1.5超、または Damodaran の対応業種が3つ以上でばらつきが大きい | 通常の色で判定し、「基準が不安定」と注記する |
| `none` | 業種の対応が単一でない、または特定企業の影響で基準にならない | 判定しない（色なし） |

注意点:
- 加重平均は大型株に引っ張られる。電機・精密のPERは加重43.5に対し、33業種の電気機器の単純値は29.1。個別銘柄が基準より「割安」に見えやすいので、信頼度を `low` にしている。

PBR: **Utilities のみ判定する**（基準2.0、Damodaran 1.8〜2.3・XLU 2.02、信頼度 high）。Software・Semiconductors・Pharmaceuticals・Technology などは自社株買い・無形資産で簿価が意味を持たないため、PBRは色なしで数値だけ表示する（Damodaran の見解と実データ、保有銘柄のPBR中央値が7〜23であることから）。

注意点:
- Damodaran の基準日は 2026-01-05（約9か月前）。次回更新は2027年1月。
- ETFの値はベンダーが違うと水準が変わる（同じS&P500でも iShares 30.16、SPDR 24.62）。そのため照合は SPDR に統一した。
- ETFの P/E は保有銘柄の加重調和平均で、業種の中央値ではない。

1. 日本株（月次）: JPX の月次統計ページ <https://www.jpx.co.jp/markets/statistics-equities/misc/04.html> から最新の Excel（perpbrYYYYMM.xlsx）を取得し、33業種を17業種に集約（対応表は <https://www.jpx.co.jp/markets/indices/line-up/files/cal2_13_sector.pdf>）。基準値・レンジ・信頼度を更新する

## 6. 利用条件

JPX の資料には無断複製・転載禁止の注記があるが、個人利用のアプリで、出典と基準日を明記して数値を使うことを本人が承認した（2026-10-03）。画面とこのファイルには出典を必ず明記する。

### 7.4 決めたライン

| 指標 | 日本株 | 米国株 | 根拠の強さ |
|---|---|---|---|
| ROE | 15%以上 | 25%以上 | 強い（日本株は東証の公式で上位19%、米国株は Damodaran の上位10〜25%の間） |
| 自己資本比率 | 70%以上 | 付けない | 中（日本株は民間集計の上位25%の境界。米国は定義が違い分布を取得できない） |
| 営業利益率 | 20%以上 | 30%以上 | 中（日本株は上位6〜10%の推計、米国株は Damodaran の上位10%付近。本人が25%から30%へ修正） |
| 売上成長率 | 15%以上 | 25%以上 | 弱い（日本株は全上場の分布を取得できず業種内の分布からの推計。米国株は上位10%寄り、本人が20%から25%へ修正） |
| 営業利益成長率 | 30%以上 | 30%以上 | 弱い（外部の分布なし。保有銘柄の上位25%のみ） |

注意:
- 良好の下限（ROE10%・自己資本比率40%・営業利益率10%・成長率0%超）は、財務健全性の現行の合格ラインそのもの。参考として、日本株の ROE10% は上位約4割、営業利益率10% はほぼ上位25%、自己資本比率40% は下位25%の境界にあたる。
- 売上・営業利益成長率は単年の前年度比で、M&A・市況の影響を受けやすい。米国の Damodaran は5年CAGRで定義が違う。
- 2026年は S&P500 の利益率・ROE が過去最高水準で、米国株の基準が高めに出る。
- 民間集計（EDINET DB）は外れ値を丸めており、最新年度が混在する。ROEは赤字企業を除くため、JPXの比率とは同じ15%でも「上位◯%」が一致しない。
